Script API

Every name a script can use without smitten. in front, generated from web/editor/core/script-api.js. Names are looked up in this order: the script's own functions, the piece (its properties, variables and methods; see Pieces), its children by capitalized name, this list, then Lua's globals. See Scripts for how a script works.

#Input

More in Input.

Call
pressed(action)True on the frame an action (jump, left, fire...) or an input ("space", "mouse:1", "pad:a") is pressed. pressed() alone: any key or button.
down(action)True while an action or input is held.
released(action)True on the frame an action or input is let go.
axis(negative, positive)-1 to 1 (in between for sticks): axis("left", "right").
vector(left, right, up, down)x, y of a direction, at most 1 long.
mouse()x, y of the mouse in the scene.
mouseScreen()x, y of the mouse on the screen, in game pixels (for UI).
wheel()How far the mouse wheel turned this frame: x, y (y > 0 is up).
touches()The fingers on the screen: a list of { id, x, y, worldX, worldY }.
stick(side, player)A gamepad stick, "left" or "right": x, y from -1 to 1.
trigger(side, player)A gamepad trigger, "left" or "right": 0 to 1.
vibrate(strength, seconds, player)Rumbles gamepads: vibrate(0.5, 0.2).
typed()The text typed this frame ("" if none); turns text input on.

#Scenes

More in Scenes and pieces.

Call
go(scene, ...)Goes to another scene; extra values go to its root's ready(...).
reload()Starts this scene again.
transition(kind, seconds, color)How go() changes scenes: transition("fade", 0.4) or transition("none").
spawn(sceneOrType, properties, parent)Makes a piece and adds it to the scene (self:spawn adds it inside this piece).
make(sceneOrType, properties)Makes a piece without adding it anywhere.
tagged(tag)Every piece with a tag.
first(tag)The first piece with a tag, or nil.
root()The scene's root piece.
camera()The camera in use, or nil.
gameA table for the whole game, kept when the scene changes: game.score += 1.
pauseGame()Pauses pieces and physics (pieces with pausable off keep running).
resumeGame()Unpauses.
isPaused()True while the game is paused.
timeScale(scale)How fast time goes: timeScale(0.5) is slow motion; timeScale() reads it.

#Sound

More in Sound and music.

Call
sfx(name, volume, pitch)Plays a sound once: sfx("coin") finds coin.sfx (or .wav, .ogg...) anywhere; sfx("hit", { volume = 0.5, pitch = 1.2 }).
music(name, options)Plays music on a loop instead of the music playing: music("theme", { volume = 0.6, fade = 1 }).
stopMusic(fade)Stops the music, fading out over fade seconds if given.
pauseMusic()Pauses the music.
resumeMusic()Continues the music.
masterVolume(volume)Every sound's volume, 0 to 1; masterVolume() reads it.

#Physics

More in Physics.

Call
raycast(x1, y1, x2, y2, tags)The first body or solid tiles on a line: { piece, x, y, nx, ny, fraction }, or nil. tags (optional) only counts pieces with one of them.
raycastAll(x1, y1, x2, y2, tags)Everything on a line, nearest first: a list of { piece, x, y, nx, ny, fraction }.
piecesAt(x, y, tags)The bodies and zones whose shapes contain a point.
overlap(kind, x, y, ...)The bodies and zones touching a shape: overlap("circle", x, y, radius) or overlap("rect", x, y, width, height).
getGravity()The scene's gravity: x, y in pixels per second per second.
setGravity(x, y)Changes the scene's gravity: setGravity(0, 0) floats everything.

#Script functions

Functions the engine calls when a script defines them:

FunctionPieces
function ready(...)PieceThe piece and everything inside it have joined the scene. The scene's root gets go()'s extra values.
function update(dt)PieceEvery frame. dt is the time since the last frame, in seconds.
function physicsUpdate(dt)Piece60 times a second, before bodies move. Use it for movement.
function draw()PieceDraw extra things on top of the piece, in its own coordinates.
function removed()PieceThe piece is leaving the scene.
function hit(other, contact)BodyIt started touching another body or solid tiles. contact has x, y (where), nx, ny (the direction from other to this body) and impulse (how hard).
function entered(zone)Body, ZoneBody: It went into a zone. Zone: A body or zone came in.
function exited(zone)Body, ZoneBody: It left a zone. Zone: A body or zone left.
function pressed()Button, Panel, PictureButton: The button was clicked, tapped, or pressed with accept while focused. Panel: The panel was clicked or tapped (not on a button inside it). Picture: The picture was clicked or tapped.
function tick()TimerThe countdown reached zero.
function finished(animation)Sprite, Particles, SoundSprite: A non-looping animation reached its last frame. Particles: The last particle is gone and no more are coming (after a burst or stop()). Good for destroy(). Sound: The sound reached its end (not when looping).
function hovered()UIThe pointer came over it (not Labels).
function unhovered()UIThe pointer left it.
