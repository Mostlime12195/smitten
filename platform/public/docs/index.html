Smitten docs

Smitten is a 2D game engine that runs in your browser. You build games out of pieces arranged in scenes, give them behavior with short Lua scripts, draw art and make sounds with the built-in tools, and publish the result for anyone to play.

If you're new, start with Getting started: it walks through a whole small game in about fifteen minutes.

#Where to look

  • Scripts explains how scripts work: variables, the functions the engine calls, events and waiting.
  • Scenes and pieces covers building scenes from code, tags, changing scenes and pausing.
  • Input, Sound and music, Camera, Tiles, Lights, UI, Physics, Pathfinding, Saving and Drawing each cover one part of a game.
  • Sharing and publishing covers putting a game on the site, and Leaderboards adding shared high scores to it there.
  • Script API and Pieces are the full reference: every function a script can call, and every piece's settings.
