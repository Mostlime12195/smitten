Smitten docs

Smitten is a 2D game engine in the browser: a fork of LÖVE 12 compiled to WebAssembly, with an editor, scenes made of pieces, and scripts you own. These pages explain how to make a game with it and list everything a script can use.

New here? Start with Getting started.

Editor toolsAdding a tool to the editor

smitten and love are the same table, so everything in LÖVE's API works too, and LÖVE games and libraries run as they are. The API pages, the piece reference and the editor's completions are generated from the same files, so they always agree with the engine (node tools/gen-docs.mjs).
