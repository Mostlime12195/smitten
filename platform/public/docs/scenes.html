Scenes and pieces

A scene is one screen of your game, for example a level, a menu or a game over screen. Smitten keeps each scene in a .scene file. A scene is a tree of pieces. For example, a level can have the player, the ground, some coins and a camera in it. The player has its image and its own camera in it. One scene runs at a time. The game starts with the main scene of the project.

You can put a scene inside a different scene (a placed scene). For example, the coin in the Platformer template is a small scene. The level has this scene in it many times. Each copy can change its properties. When you change the coin scene, all the copies change.

#Finding pieces
Look, CameraA child, found by its name (names that start with a capital letter find children)
find("UI/Score")A piece, found by its path from this piece. .. goes up one level of the tree
findDeep("Score")The first piece with that name, at any level inside this piece
findChildOfType("Sprite")The first child of a piece type
parent, childrenparent is the piece that has this piece in it. children are the pieces in this piece
root()The top piece of the scene
first("player"), tagged("coin")first gives the first piece with a tag. tagged gives all the pieces with the tag

#Tags

Tags are words that you put on pieces, for example player, enemy or coin. Scripts use tags to find pieces and to know which piece is which. Add tags in the Inspector. In a script, tag(name) adds a tag, and untag(name) removes a tag.

other:is("enemy") checks for a tag, or for a piece type (other:is("Body")). hasAnyTag("enemy, spikes") checks for more than one tag at the same time. Bodies and Zones also use tags to find what they hit (Physics).

#Making and removing pieces

spawn makes a new piece from a scene file or a piece type. Then it adds the piece to the scene:

spawn("scenes/bullet.scene", { x = x, y = y, rotation = rotation })
spawn("Text", { text = "+10", x = x, y = y - 20 })
self:spawn("scenes/hat.scene")           -- put the new piece inside this piece

local enemy = make("scenes/enemy.scene") -- make a piece, but do not add it now
Enemies:add(enemy)

destroy()                                -- remove this piece

destroy() removes a piece and all the pieces in it, at the end of the frame. remove() takes a piece out immediately, but does not destroy it. Then you can use add to put it in a different place.

#Changing scenes

go("scenes/level2.scene") changes to a different scene at the end of the frame. go() gives its extra values to the root of the new scene, in its ready(...):

go("scenes/gameover.scene", score)

-- on the root piece of the game over scene
function ready(score)
  find("Score").text = `Score: {score}`
end

reload() starts the current scene again.

  • transition("fade", 0.4) makes the screen fade to black and back when the scene changes.
  • transition("fade", 0.4, {1, 1, 1}) fades through a different color.
  • transition("none") makes the scene change immediately again.

#The game table

When a scene ends, all the values in it go away. game is a table that all scripts can use. It stays while the game runs. Because of this, it is the correct place for values such as lives and the score:

game.lives = (game.lives or 3) - 1

To keep a value after the game closes, save it.

#Pausing and slow motion

pauseGame() stops these:

  • update and physicsUpdate of the pieces
  • physics
  • animations
  • timers
  • tweens

The screen continues to draw, and the UI continues to work. Some pieces continue to run: a piece with its pausable property off, and all the pieces in it. Put your pause menu inside such a piece:

-- on a Group with pausable off. The pause menu is in this Group.
function update(dt)
  if pressed("pause") then
    if isPaused() then resumeGame() else pauseGame() end
    visible = isPaused()
  end
end

timeScale(0.5) makes the game run at half speed, for slow motion. timeScale(1) makes the speed normal again. Music plays at its normal speed at all time scales.

#Position, size and drawing order

Group, and each piece type that has Group as its base, are pieces that you can see in the scene. These pieces have x, y, rotation, scaleX, scaleY, visible, tint and layer. A position is relative to the parent piece. y increases downwards. A piece on a higher layer is on top of a piece on a lower layer.

#Angles

All angles are in degrees, clockwise. rotation = 90 is a quarter turn, and 0 points to the right. This is true for all the angles in scripts:

  • rotation
  • angleTo()
  • spin of a Body (degrees each second)
  • minAngle of a Joint
  • direction of a Particles piece

The Inspector shows the same numbers.

rotation = angleTo(first("player"))           -- point to the player
rotation += 180 * dt                            -- half a turn each second

-- Move in the direction that the piece points to: the x and y of a step at an angle.
vx, vy = smitten.math.direction(rotation, 300)

-- The opposite: the angle of a direction.
rotation = smitten.math.angle(vx, vy)

The Lua functions math.sin and math.cos use radians. Give them math.rad(angle). math.deg(radians) changes radians to degrees. The low-level smitten.graphics functions (rotate, draw) also use radians.
