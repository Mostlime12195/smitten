Scenes and pieces

A scene is one screen of your game, such as a level, a menu or a game over screen, saved as a .scene file. It's a tree of pieces: a level might hold the player, the ground, some coins and a camera, and the player holds its picture and its own camera. One scene runs at a time, starting with the project's main scene.

Scenes can be placed inside other scenes. The Platformer template's coin is its own small scene, placed many times in the level; each copy can change its settings, and editing the coin scene changes them all.

#Finding pieces
Look, CameraA child, by its name (names starting with a capital letter work like this)
find("UI/Score")A piece by its path from this one; .. goes up a level
findDeep("Score")The first piece with that name anywhere inside this one
findChildOfType("Sprite")The first child of a type
parent, childrenThe piece this one is inside; the pieces inside it
root()The scene's top piece
first("player"), tagged("coin")The first piece with a tag; every piece with it

#Tags

Tags are labels you give pieces, like player, enemy or coin, so scripts can find them and tell them apart. Add them in the Inspector, or with tag(name) and untag(name) from a script.

other:is("enemy") checks for a tag, or a type (other:is("Body")). hasAnyTag("enemy, spikes") checks several at once. Bodies and Zones also use tags to decide what they bump into (Physics).

#Making and removing pieces

spawn makes a new piece, from a scene file or a piece type, and adds it to the scene:

spawn("scenes/bullet.scene", { x = x, y = y, rotation = rotation })
spawn("Text", { text = "+10", x = x, y = y - 20 })
self:spawn("scenes/hat.scene")           -- inside this piece instead

local enemy = make("scenes/enemy.scene") -- made, but not added yet
Enemies:add(enemy)

destroy()                                -- remove this piece

destroy() removes a piece and everything inside it at the end of the frame. remove() takes a piece out straight away without destroying it, so you can add it somewhere else.

#Changing scenes

go("scenes/level2.scene") switches to another scene at the end of the frame. Any extra values are handed to the new scene's root, in its ready(...):

go("scenes/gameover.scene", score)

-- on the game over scene's root piece
function ready(score)
  find("Score").text = `Score: {score}`
end

reload() starts the current scene again. transition("fade", 0.4) makes scene changes fade through black (or another color: transition("fade", 0.4, {1, 1, 1})), and transition("none") goes back to instant cuts.

#The game table

Everything in a scene is gone when it ends. game is a table every script can use that lasts for the whole time the game runs, which makes it the place for things like lives and score:

game.lives = (game.lives or 3) - 1

To keep something after the game closes, save it.

#Pausing and slow motion

pauseGame() stops pieces' update and physicsUpdate, physics, animations, timers and tweens; the screen still draws and UI still responds. Pieces whose pausable setting is off, and everything inside them, keep running, so put your pause menu inside one:

-- on a Group with pausable off, holding the pause menu
function update(dt)
  if pressed("pause") then
    if isPaused() then resumeGame() else pauseGame() end
    visible = isPaused()
  end
end

timeScale(0.5) runs the game at half speed for a slow-motion moment, and timeScale(1) puts it back. Music keeps playing normally through both.

#Position, size and drawing order

Pieces that appear in the world (Group and everything based on it) have x, y, rotation, scaleX, scaleY, visible, tint and layer. Positions are measured from the parent piece, and y grows downwards. Higher layers draw on top.

#Angles

Every angle is in degrees, clockwise: rotation = 90 is a quarter turn, and 0 points right. That goes for everything a script meets: rotation, angleTo(), a Body's spin (degrees a second), a Joint's minAngle, a Particles piece's direction, and the Inspector shows the same numbers.

rotation = angleTo(first("player"))           -- face the player
rotation += 180 * dt                            -- half a turn a second

-- Fly the way the piece faces: the x and y of a step at an angle.
vx, vy = smitten.math.direction(rotation, 300)

-- And back: the angle of a direction.
rotation = smitten.math.angle(vx, vy)

Lua's own math.sin and math.cos take radians, so give them math.rad(angle); math.deg(radians) goes the other way. The low-level smitten.graphics calls (rotate, draw) take radians too.
