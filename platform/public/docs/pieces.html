Pieces

Each piece has its own properties and the properties of its base type. In the script of the piece, use the names directly: x = 10, move(), function clicked() end. For a different piece, use the piece: other.x, other:move(), other:on("clicked", fn). Angles are in degrees, in code and in the Inspector.

#Basic

#Piece

Everything in a scene is a piece. Pieces nest: the children of a piece belong to it.

A base for other piece types. You do not add it to a scene yourself.

PropertyTypeDefault
pausablebooltrueWhen this is on, the piece stops while the game is paused. When it is off, this piece and its children keep running (for pause menus).
Method
find(path)Returns a child by name, or a piece deeper inside by path ("UI/Score"). Returns nil if there is no such piece.
findDeep(name)Returns the first piece with this name at any depth inside this piece.
findChildOfType(type)Returns the first child of a piece type ("Sprite"), or nil.
isA(type)Returns true if the piece is of a piece type, or of a type that extends it.
add(piece)Adds a piece as the last child and returns it.
remove()Takes the piece out of its parent now, but does not destroy it.
spawn(sceneOrType, properties?)Makes a piece from a scene file or a piece type and adds it as a child.
destroy()Removes the piece and everything inside it at the end of the frame.
tag(name)Adds a tag.
untag(name)Removes a tag.
hasTag(name)Returns true if the piece has the tag.
hasAnyTag(tags)Returns true if the piece has one or more of the tags in a comma-separated list: hasAnyTag("enemy, spikes").
is(tagOrType)Returns true if the piece has the tag or is of the piece type: other:is("enemy"), other:is("Body").
on(event, fn)Calls fn(...) when the piece sends the event. Returns a handle with :off().
emit(event, ...)Sends an event: it calls the script function with that name and every function that on() added.
getPath()Returns the path of the piece from the root piece of the scene, for example "Level/Player".
isAlive()Returns true while the piece is in the running scene and destroy() has not removed it.
Event (a function in its script)
function ready(...)The engine calls it when the piece and its children join the scene. The root piece of the scene gets the extra values of go().
function update(dt)The engine calls it every frame. dt is the time since the last frame, in seconds.
function physicsUpdate(dt)The engine calls it 60 times per second, before bodies move. Use it for movement.
function draw()The engine calls it every frame. Draw extra things on top of the piece here, in the piece's own coordinates.
function removed()The engine calls it when the piece leaves the scene.

#Group

A piece with a position. Use it to hold other pieces (they move with it) or to run a script.

Extends Piece.

PropertyTypeDefault
xnumber (px)0The horizontal position, measured from the parent.
ynumber (px)0The vertical position, measured from the parent. y increases downwards.
rotationangle (°)0°The rotation, clockwise, in degrees: 90 is a quarter turn.
scaleXnumber1Multiplies the width. A negative value mirrors the piece left to right.
scaleYnumber1Multiplies the height. A negative value mirrors the piece top to bottom.
visiblebooltrueWhen this is on, this piece and everything inside it are visible.
tintcolor{1, 1, 1, 1}Multiplies the colors of this piece and everything inside it.
layerint0The engine draws higher layers on top. It draws pieces on the same layer in scene order.
litbooltrueWhen this is on, Lights and the Tint change how this piece and everything inside it look. When it is off, they always have full brightness (glows, lasers, signs).
Method
worldPosition()Returns the position of the piece in the scene (not measured from its parent): x, y.
setWorldPosition(x, y)Moves the piece to a position in the scene.
toWorld(x, y)Takes a point measured from this piece and returns it as a point in the scene.
fromWorld(x, y)Takes a point in the scene and returns it measured from this piece.
lookAt(x, y)Turns the piece to face a point in the scene.
distanceTo(pieceOrX, y?)Returns the distance in pixels to another piece or a point.
angleTo(pieceOrX, y?)Returns the angle towards another piece or a point, in degrees. rotation = angleTo(target) turns the piece to face it.
moveToward(x, y, distance)Moves at most distance pixels towards a point. Returns true when the piece is at the point.
translate(dx, dy)Moves the piece by an offset.

#Timer

Counts down and calls tick() when the countdown reaches zero.

Extends Piece.

PropertyTypeDefault
secondsnumber (s)1The time between ticks, in seconds.
runningboolfalseWhen this is on, the timer counts down. If it is on in the scene file, the timer starts with the scene.
loopbooltrueWhen this is on, the timer keeps ticking. When it is off, the timer ticks once and stops.

timeLeft: The time until the next tick, in seconds.

Method
start(seconds?)Starts the countdown, or starts it again from the beginning.
stop()Stops the countdown.
Event (a function in its script)
function tick()The engine calls it when the countdown reaches zero.

#Things you see

#Sprite

Draws an image, or an animation from a .sprite file or a sprite sheet.

Extends Group.

PropertyTypeDefault
imageresource""An image (.png, .jpg), or a .sprite file with animation frames and animations.
animationanimation""The animation to play, from the .sprite file.
playingbooltrueWhen this is on, the animation plays.
speednumber1The animation speed: 2 is twice as fast.
frameint0The animation frame that the sprite shows, counting from 0.
columnsint1The number of animation frames across, for a sprite sheet without a .sprite file.
rowsint1The number of animation frames down, for a sprite sheet without a .sprite file.
centeredbooltrueWhen this is on, the center of the image is at the position of the piece. The origin in a .sprite file has priority over this.
flipXboolfalseWhen this is on, the sprite mirrors the image left to right.
flipYboolfalseWhen this is on, the sprite mirrors the image top to bottom.
Method
play(name?, restart?)Plays an animation, or continues the current one. With restart, it plays from the first animation frame.
pause()Stops the animation where it is. play() continues it.
stop()Stops the animation and goes back to its first animation frame.
hasAnimation(name)Returns true if the .sprite file has an animation with this name.
animations()Returns the names of the animations in the .sprite file, sorted.
getSize()Returns the width and height of one animation frame, in pixels.
getRect()Returns the rectangle that the image covers, in the piece's own coordinates: x, y, width, height.
Event (a function in its script)
function finished(animation)The engine calls it when an animation that does not loop reaches its last animation frame.

heightnumber (px)64The height of the rectangle.

centeredbooltrueWhen this is on, the center of the rectangle is at the position of the piece.
Method

#Text

Shows words in the scene, for example a sign or a damage number. For scores and menus, use Label.

Extends Group.

PropertyTypeDefault
texttext"Text"The text that the piece shows.
fontresource""A .ttf or .otf font file, "pixel" for the built-in pixel font, or empty for the default font.
sizeint (px)16The font size.
colorcolor{1, 1, 1, 1}The text color.
alignenum"center"Aligns the text around the position of the piece. justify stretches wrapped lines to the same width.
wrapnumber (px)0The text wraps lines that are longer than this. 0 means that lines never wrap.
wrapByenum"word"Where the text breaks lines that are too long: between words, or after any character (for languages without spaces, like Japanese).
richboolfalseWhen this is on, the text reads text tags: [b]bold[/b], [color=red]red[/color], [wave]wavy[/wave] and more (see the Text page of the docs). Type [[ for a real square bracket.
outlineboolfalseWhen this is on, the text has a dark outline.
fontBoldresource""The font file for [b]bold[/b] words. If it is empty, the engine makes the font thicker.
fontItalicresource""The font file for [i]italic[/i] words. If it is empty, the engine slants the font.
lineHeightnumber1The distance between lines: 1 is the font's own spacing, 1.5 leaves half a line between them.
letterSpacingnumber (px)0Extra space between letters. A negative value pushes them closer together.
outlineWidthnumber (px)0The thickness of the outline. 0 keeps it one screen pixel thin.
outlineColorcolor{0, 0, 0, 0.8}The color of the outline.
shadowboolfalseWhen this is on, the text has a shadow behind it.
shadowColorcolor{0, 0, 0, 0.5}The color of the shadow.
shadowXnumber (px)2How far right the shadow is. A negative value moves it left.
shadowYnumber (px)2How far down the shadow is. A negative value moves it up.
visibleCharactersint-1The number of characters that show, counting from the start: 0 shows none, -1 shows all. reveal() increases this for a typewriter effect.
visibleRationumber1The part of the text that shows: 0 is none, 0.5 is the first half, 1 is all of it. Tween it to show the text gradually.
Method
measure()Returns the size of the text in its current layout: width, height.
lineCount()Returns the number of lines in the text.
characterCount()Returns the number of characters in the text. Text tags and line breaks do not count.
characterRect(index)Returns the position and size of a character, measured from the position of the piece: x, y, width, height. Use it to put a cursor or a sparkle on the character.
characterAt(x, y)Returns the number of the character at a point (measured from the position of the piece), or nil.
linkAt(x, y)Returns the name of the [link=name] at a point (measured from the position of the piece), or nil.
reveal(charactersPerSecond?, from?)Shows the text one character at a time, like a typewriter (30 characters per second if you do not give a speed). Returns a handle with cancel(), after(fn) and wait(seconds). [pause=0.5] and [speed=10] in rich text change the speed.
skip()Shows all of the text now and stops a reveal().
Event (a function in its script)
function revealed(index, char)The engine calls it when reveal() shows one more character. Use it to play a blip, or to wait at a full stop.
function finished()The engine calls it when reveal() has shown all of the text.
function eachCharacter(c)The engine calls it for every character each time it draws the text. Use it to move or color the character: c.y = math.sin(c.time * 4 + c.index) * 3. You can change x, y, rotation, scale, color, alpha and visible of c. You can read index, count, char, line, time and since. The engine uses the same table c for every character, so do not keep it.

#Tiles

A grid of tiles from a tileset. Solid tiles block bodies.

Extends Group.

PropertyTypeDefault
tilesetresource""The .tileset file: an image cut into tiles, with tile properties such as solid.
solidbooltrueWhen this is on, tiles that the tileset marks as solid block bodies. When it is off, every tile is only decoration.
castShadowsboolfalseWhen this is on, tiles that the tileset marks as solid block the Lights that have shadows on.
animatebooltrueWhen this is on, animated tiles play. When it is off, they stop on the animation frame that they show.
Method
getTile(column, row)Returns the tile number in a cell, or -1 if the cell is empty.
setTile(column, row, tile)Changes the tile in a cell (-1 empties the cell).
tileInfo(tile)Returns the tile properties of a tile in the tileset (solid, name, ...).
cellAt(x, y)Returns the cell under a point in the scene: column, row.
cellPosition(column, row)Returns the scene position of the top-left corner of a cell.
cellsWith(tile?)Returns a list of {column, row, tile} for every painted cell (or every cell with that tile).
fill(column, row, columns, rows, tile)Sets a rectangle of cells to one tile (-1 empties them).
clear()Empties every cell.
tileAt(x, y)Returns the tile number under a point in the scene, or -1.
isSolid(column, row)Returns true if the tileset marks the tile in the cell as solid (and solid is on).
neighbors(column, row, diagonal?)Returns the adjacent cells as {column, row, tile}: 4 cells, or 8 with diagonal.
cellCenter(column, row)Returns the scene position of the center of a cell.
getTileSize()Returns the size of one cell in the scene: width, height.
getBounds()Returns the painted area in the scene: x, y, width, height (all 0 if no cell has a tile).
newPathGrid(options?)Returns a grid to find paths through these tiles (solid tiles are solid cells): grid:findPoints(x, y, toX, toY). The grid changes when setTile() changes a tile.
setTerrain(column, row, terrain)Paints a terrain of the tileset (by name; nil erases) in a cell. It also changes the tiles of the 8 cells around it so that the edges fit.
getTerrain(column, row)Returns the name of the terrain of the tile in the cell, or nil.
fillTerrain(column, row, columns, rows, terrain)Paints a terrain (nil erases) in a rectangle of cells. It makes the edges fit, also at the cells around the rectangle.
terrains()Returns the names of the terrains in the tileset.

#Background

Scrolls the pieces inside it slower or faster than the camera (parallax), for far hills, clouds and skies. It can repeat them without end.

Extends Group.

PropertyTypeDefault
scrollXnumber0.5How much it moves sideways when the camera moves. 1 moves with the scene, 0.5 moves half as much (far away), and 0 stays on the screen. Use more than 1 for things in front.
scrollYnumber0.5The same as scrollX, but up and down.
repeatWidthnumber (px)0The pieces inside repeat sideways at this distance, as far as the view goes. 0 draws them once. Use the width of the image.
repeatHeightnumber (px)0The pieces inside repeat up and down at this distance. 0 draws them once.
driftXnumber (px/s)0Moves sideways by itself at this speed, like clouds. A negative value moves it left.
driftYnumber (px/s)0Moves down by itself at this speed. A negative value moves it up.
offsetXnumber (px)0Moves the pieces inside sideways. Change it from a script to scroll by hand.
offsetYnumber (px)0Moves the pieces inside up or down.
leftnumber (px)noneWhile the view is left of this edge, the background stops its own scrolling and moves with the scene. If it is empty, there is no edge.
topnumber (px)noneWhile the view is above this edge, the background stops its own scrolling and moves with the scene.
rightnumber (px)noneWhile the view is right of this edge, the background stops its own scrolling and moves with the scene.
bottomnumber (px)noneWhile the view is below this edge, the background stops its own scrolling and moves with the scene.
Method
getScroll()Returns the current distance between where the engine draws it and where you put it: x, y.

#Camera

Decides which part of the scene is on the screen. Put it inside the player piece to follow the player.

Extends Group.

PropertyTypeDefault
activebooltrueWhen this is on, the game uses this camera. If more than one camera is active, the first in the scene has priority.
zoomnumber1The zoom: 2 shows everything twice as big.
smoothingnumber0How gently the camera catches up: 0 follows exactly, 5 glides.
targetpiecepath""A piece to follow, anywhere in the scene. If it is empty, the camera stays at its own position.
offsetXnumber (px)0The camera looks this far to the right of what it follows.
offsetYnumber (px)0The camera looks this far below what it follows.
leftnumber (px)noneThe camera does not show anything to the left of this edge. If it is empty, there is no edge.
topnumber (px)noneThe camera does not show anything above this edge.
rightnumber (px)noneThe camera does not show anything to the right of this edge.
bottomnumber (px)noneThe camera does not show anything below this edge.
Method
shake(strength?, seconds?)Shakes the view: shake(6, 0.3).
follow(piece)Follows a piece. With nil, the camera goes back to target, or to its own position.
snap()Moves directly to what it follows, without smoothing (for example, after a teleport).
setLimits(left, top, right, bottom)Sets the edges that the camera does not show past (nil for no edge).
limitTo(piece)Keeps the view inside the painted part of a Tiles piece.
makeCurrent()Makes this the camera in use and turns the other cameras off.
getView()Returns the part of the scene that is on the screen: x, y, width, height.
screenToWorld(sx, sy)Takes a point on the screen and returns it as a point in the scene.
worldToScreen(x, y)Takes a point in the scene and returns it as a point on the screen.

#Particles

Sprays particles: smoke, sparks, dust, rain, explosions.

Extends Group.

PropertyTypeDefault
emittingbooltrueWhen this is on, the piece makes new particles.
ratenumber (/s)30The number of particles per second.
burstboolfalseWhen this is on, the piece makes one burst of rate particles and then stops.
lifetimenumber (s)1How long each particle lives, in seconds.
imageresource""The image of each particle. If it is empty, the piece draws soft dots.
speednumber (px/s)100The starting speed of each particle.
speedRandomnumber0.5How much the speed changes from particle to particle (0 to 1).
directionangle (°)-5156.62°The direction in which particles move, in degrees: 0 is right, 90 is down, -90 is up.
spreadangle (°)1718.87°How much the direction changes to each side, in degrees.
gravityXnumber (px/s²)0A constant pull sideways.
gravityYnumber (px/s²)0A constant pull down.
sizeStartnumber (px)8The size of a particle when it starts.
sizeEndnumber (px)2The size of a particle when it fades out.
colorStartcolor{1, 0.85, 0.4, 1}The color of a particle when it starts.
colorEndcolor{1, 0.3, 0.1, 0}The color of a particle when it fades out.
followPieceboolfalseWhen this is on, particles move with the piece. When it is off, they stay where they started.
Method
emit(count)Makes count particles now. emit("event", ...) still sends an event.
start()Starts to make particles (a burst makes its particles again).
stop()Stops making particles. The particles that are already out stay until their lifetime ends.
clear()Removes every particle now.
restart()Removes every particle and starts again.
getCount()Returns the number of particles that are out now.
Event (a function in its script)
function finished()The engine calls it when the last particle is gone and no more particles will come (after a burst or stop()). Use it to destroy() the piece.

#Light and shadow

#Light

Shines on the pieces around it. With a dark Tint in the scene, it is a torch at night. Without a Tint, it makes things brighter.

Extends Group.

PropertyTypeDefault
kindenum"point"point shines out from the position of the piece, as far as radius. sun lights the whole view from one side, in the direction that the piece points.
radiusnumber (px)200How far the light goes.
brightnessnumber1How strong the light is: 0 is dark, 2 is twice as bright.
colorcolor{1, 1, 1, 1}The color of the light.
imageresource""An image of the shape of the light, white where it shines: a beam, a window. If it is empty, the light is a soft round glow.
blendenum"add"add makes the pieces that it shines on brighter. subtract makes them darker (a dark patch). mix replaces the light that is there with the color of this light.
offboolfalseWhen this is on, the light is off.
lightstags""The light shines only on pieces with one of these tags, and on what is inside them. If it is empty, it shines on every piece.
fromLayernumbernoneThe light shines only on pieces on this layer and higher. If it is empty, there is no limit.
toLayernumbernoneThe light shines only on pieces on this layer and lower. If it is empty, there is no limit.
shadowsboolfalseWhen this is on, Occluders, and Tiles with castShadows on, block this light.
shadowColorcolor{0, 0, 0, 1}The part of the light that stays in a shadow: black is none. A transparent color makes weaker shadows.
shadowSoftnessnumber (px)0Blurs the edges of the shadows by this distance. 0 keeps them sharp and is the fastest.
shadowLengthnumber (px)0The length of the shadows of a sun. 0 makes shadows that never end.
shadowsFromtags""Only Occluders and Tiles with one of these tags block the light. If it is empty, all of them block it. The tag can be on the piece that holds the Occluder.

#Occluder

Blocks light: Lights with shadows on make a shadow behind it. Put it inside a piece to fit the Sprite or Shape of that piece.

Extends Group.

PropertyTypeDefault
shapeenum"auto"auto fits the Sprites and Shapes inside it. If it has none, it fits the ones in the piece that it is inside.
widthnumber (px)32The width of the rectangle.
heightnumber (px)32The height of the rectangle.
radiusnumber (px)16The radius of the circle.
pointspoints{0, -16, 16, 16, -16, 16}The corner points x1, y1, x2, y2, ... of the outline.
offboolfalseWhen this is on, light goes through it.

#Tint

Colors the whole scene, but not the on-screen UI: dark blue for night, orange for sunset. Lights shine on top of it. If there is more than one Tint, the first in the scene has priority.

Extends Piece.

PropertyTypeDefault
colorcolor{0.35, 0.4, 0.6, 1}The engine multiplies the colors of every piece by this color. White changes nothing. Black hides everything that no light reaches.
offboolfalseWhen this is on, the tint is off.
fromLayernumbernoneThe Tint colors only pieces on this layer and higher. If it is empty, there is no limit.
toLayernumbernoneThe Tint colors only pieces on this layer and lower. If it is empty, there is no limit.

#Bodies and zones

#Body

A solid piece. Its motion is still (walls), scripted (move() moves it) or physics (the physics engine moves it). It takes its shape from a Sprite or Shape inside it.

Extends Group. Uses the physics2d (Box2D) module.

PropertyTypeDefault
motionenum"scripted"still: it moves only when a script sets x or y. scripted: move() moves it. physics: the physics engine moves it.
shapeenum"auto"auto fits the Sprites and Shapes inside it. capsule has round ends. none means that only Hitboxes give it a shape.
widthnumber (px)32The width of the rectangle or capsule.
heightnumber (px)32The height of the rectangle or capsule.
radiusnumber (px)16The radius of the circle.
pointspoints{0, -16, 16, 16, -16, 16}The corner points x1, y1, x2, y2, ... (8 corners at most; the engine fills in dents).
vxnumber (px/s)0The horizontal speed, in pixels per second.
vynumber (px/s)0The speed down (a negative value is up). For scripted motion, move() uses it. For physics motion, it is the current speed.
spinangle (°/s)0°How fast it turns, in degrees per second (clockwise is positive): 360 is a full turn every second. For scripted motion, move() turns it at this speed.
slopeangle (°)2578.31°The steepest surface that is still ground, in degrees. move() walks up it and does not slide back.
massnumber (kg)1The mass, in kilograms. A scripted body pushes physics bodies by its mass against their mass.
frictionnumber0.3How much it grips what it touches: 0 is ice.
bouncenumber0How much it bounces: 0 is no bounce, 1 bounces forever.
gravityScalenumber1How strongly gravity pulls it: 1 is normal, 0 floats, -1 falls up.
dragnumber0Air resistance: it slows the movement down.
spinDragnumber0Slows the turning down.
fixedRotationboolfalseWhen this is on, the body never tips over or turns.
bulletboolfalseWhen this is on, the physics engine checks collisions continuously against moving bodies. Use it for small, fast bodies.
asleepboolfalseWhen this is on, the body stays at rest until something touches it. Physics bodies go to sleep when they stop.
passThroughtags""The tags of things that it does not bump into, for example "ghost, pickup" ("tiles" for solid tiles).
Method
move()Moves by vx, vy for this physics step. It slides along walls, climbs slopes, rides on platforms and pushes physics bodies.
moveBy(dx, dy)Moves by an offset and stops at the first thing in the way. Returns what it hit, or nil.
onGround()Returns true if the last move ended on top of something.
onWall()Returns true if the last move ran into a wall.
onCeiling()Returns true if the last move ran into a ceiling.
applyImpulse(ix, iy, x?, y?)Changes the speed immediately by impulse / mass. At a point, it also makes the body spin.
applyForce(fx, fy, x?, y?)Pushes with a force for this physics step, at the center or at a point. Call it in every physicsUpdate.
applyTorque(torque)Turns a physics body steadily for this physics step.
applyAngularImpulse(impulse)Gives a physics body a sudden twist.
push(ix, iy)Does the same as applyImpulse(ix, iy).
wake()Wakes up a physics body that sleeps.
grab(x, y, strength?)Holds the body at a point in the scene for dragTo(). drop() lets it go with its momentum.
dragTo(x, y)Moves the point that grab() holds towards x, y.
drop()Lets go after grab(). A physics body keeps its speed.
touching(tagOrPiece)Returns the first body or zone with a tag (or that piece) that touches this one, or nil.
isTouching(other)Returns true if it touches a piece (a body, zone or Tiles) or anything with a tag.
contacts()Returns the current contacts: {piece, x, y, nx, ny, impulse}.
touchingTile(setting)Returns the tile properties of a touching tile that has this tile property (for example "damage"), or nil.
getSize()Returns the size of the box around its shapes: width, height.
Event (a function in its script)
function hit(other, contact)The engine calls it when the body starts to touch a body or solid tiles. contact has x, y, nx, ny (from other to this body) and impulse.
function entered(zone)The engine calls it when the body goes into a zone.
function exited(zone)The engine calls it when the body leaves a zone.

#Zone

An area that detects bodies and zones that go in and out. It does not block them, and it ignores still bodies. When forces is on, it changes the gravity, drag and push of physics bodies inside it.

Extends Group. Uses the physics2d (Box2D) module.

PropertyTypeDefault
shapeenum"auto"auto fits the Sprites and Shapes inside it. The shapes turn and scale with the Zone.
widthnumber (px)32The width of the rectangle or capsule.
heightnumber (px)32The height of the rectangle or capsule.
radiusnumber (px)16The radius of the circle.
pointspoints{0, -16, 16, 16, -16, 16}The corner points x1, y1, x2, y2, ... (8 corners at most).
detectstags""The Zone notices only things with one of these tags. If it is empty, it notices everything.
activebooltrueWhen this is on, the Zone notices things that go in and out.
forcesboolfalseWhen this is on, the Zone changes how physics bodies move inside it: gravity, drag and a steady push.
gravityenum"scene"scene: bodies feel only the scene's gravity. add: the Zone's gravity adds to the scene's gravity. replace: bodies feel the Zone's gravity instead.
toCenterboolfalseWhen this is on, the Zone pulls towards its position, like a planet, and not in one direction.
gravityXnumber (px/s²)0The Zone's gravity, to the right (negative is to the left).
gravityYnumber (px/s²)0The Zone's gravity, down (negative is up). With replace, 0 and 0 make bodies float.
gravityStrengthnumber (px/s²)980How hard the Zone pulls towards its position. The pull is the same everywhere in the Zone.
dragnumber0Slows down the movement of bodies inside, like water or thick air. It adds to their own drag.
spinDragnumber0Slows down the turning of bodies inside.
pushXnumber0A steady push to the right on each body inside, for wind, currents and conveyor belts. A heavy body speeds up less.
pushYnumber0A steady push down on each body inside (negative is up).
Method
