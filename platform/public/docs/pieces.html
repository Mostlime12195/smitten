Pieces

Each piece has its own properties plus its base type's. In its own script: x = 10, move(), function clicked() end. On another piece: other.x, other:move(), other:on("clicked", fn). Angles are degrees, in code and in the Inspector.

#Basic

#Piece

Everything in a scene is a piece. Pieces nest: a piece's children belong to it.

A base for other types; not added itself.

PropertyTypeDefault
pausablebooltrueStops while the game is paused. Off: this piece and its children keep running (pause menus).
Method
find(path)A child by name, or a deeper piece by path ("UI/Score"); nil if there isn't one.
findDeep(name)The first piece with this name anywhere inside this one.
findChildOfType(type)The first child of a type ("Sprite"), or nil.
isA(type)True if the piece is of a type, or a type made from it.
add(piece)Adds a piece as the last child; returns it.
remove()Takes the piece out of its parent now, without destroying it.
spawn(sceneOrType, properties?)Makes a piece from a scene file or type and adds it as a child.
destroy()Removes the piece and everything inside it at the end of the frame.
tag(name)Adds a tag.
untag(name)Takes a tag away.
hasTag(name)True if the piece has the tag.
hasAnyTag(tags)True if the piece has any of the tags in a comma-separated list: hasAnyTag("enemy, spikes").
is(tagOrType)True if the piece has the tag or is of the type: other:is("enemy"), other:is("Body").
on(event, fn)Calls fn(...) on an event. Returns a handle with :off().
emit(event, ...)Fires an event: calls the script's function of that name and every listener.
getPath()The piece's path from the scene's root, like "Level/Player".
isAlive()True while the piece is in the running scene and not destroyed.
Event (a function in its script)
function ready(...)The piece and its children joined the scene. The scene root gets go()'s extra values.
function update(dt)Every frame. dt is the time since the last frame, in seconds.
function physicsUpdate(dt)60 times a second, before bodies move. Use it for movement.
function draw()Draw extra things on top of the piece, in its own coordinates.
function removed()The piece is leaving the scene.

#Group

A piece with a position. Use it to hold other pieces (they move with it) or to run a script.

Extends Piece.

PropertyTypeDefault
xnumber (px)0Position, measured from the parent.
ynumber (px)0Position, measured from the parent. y grows downwards.
rotationangle (°)0°Turn, clockwise, in degrees: 90 is a quarter turn.
scaleXnumber1Width multiplier. Negative mirrors it.
scaleYnumber1Height multiplier. Negative flips it.
visiblebooltrueShow this piece and everything inside it.
tintcolor{1, 1, 1, 1}Multiplies the colors of this piece and everything inside it.
layerint0Higher layers are drawn on top. Pieces on the same layer draw in scene order.
litbooltrueLights and the Tint change how this piece and everything inside it looks. Off: always at full brightness (glows, lasers, signs).
Method
worldPosition()Where the piece is in the scene (not measured from its parent): x, y.
setWorldPosition(x, y)Moves the piece to a place in the scene.
toWorld(x, y)A point measured from this piece, as a point in the scene.
fromWorld(x, y)A point in the scene, measured from this piece.
lookAt(x, y)Turns the piece to face a point in the scene.
distanceTo(pieceOrX, y?)Distance in pixels to another piece or a point.
angleTo(pieceOrX, y?)The angle towards another piece or a point, in degrees: rotation = angleTo(target) faces it.
moveToward(x, y, distance)Moves at most distance pixels towards a point; true once it's there.
translate(dx, dy)Moves the piece by an offset.

#Timer

Counts down and calls tick().

PropertyTypeDefault

Method

#Things you see

#Text

Words in the game world, like a sign or a damage number. For scores and menus, use Label.

Extends Group.

PropertyTypeDefault
texttext"Text"What it says.
fontresource""A .ttf/.otf font file, "pixel" for the built-in pixel font, or empty for the default font.
sizeint (px)16Font size.
colorcolor{1, 1, 1, 1}Text color.
alignenum"center"Lines up the text around the piece's position. justify stretches wrapped lines to the same width.
wrapnumber (px)0Wrap lines longer than this; 0 never wraps.
wrapByenum"word"Where a line that's too long is broken: between words, or after any character (for writing without spaces, like Japanese).
richboolfalseReads tags in the text: [b]bold[/b], [color=red]red[/color], [wave]wavy[/wave] and more (see the Text page of the docs). Type [[ for a real square bracket.
outlineboolfalseA dark outline around the text.
fontBoldresource""The font file for [b]bold[/b] words. Empty: the font is made thicker instead.
fontItalicresource""The font file for [i]italic[/i] words. Empty: the font is slanted instead.
lineHeightnumber1How far apart lines are: 1 is the font's own spacing, 1.5 leaves half a line between them.
letterSpacingnumber (px)0Extra room between letters (negative squeezes them together).
outlineWidthnumber (px)0How thick the outline is. 0 keeps it one screen pixel thin.
outlineColorcolor{0, 0, 0, 0.8}The outline's color.
shadowboolfalseA shadow behind the text.
shadowColorcolor{0, 0, 0, 0.5}The shadow's color.
shadowXnumber (px)2How far right the shadow falls (negative: left).
shadowYnumber (px)2How far down the shadow falls (negative: up).
visibleCharactersint-1How many characters show, counted from the start: 0 shows nothing, -1 shows them all. reveal() counts this up for a typewriter effect.
visibleRationumber1How much of the text shows: 0 is nothing, 0.5 the first half, 1 all of it. Tween it to reveal the text smoothly.
Method
measure()How big the text is as it's laid out now: width, height.
lineCount()How many lines the text takes.
characterCount()How many characters the text has (tags and line breaks don't count).
characterRect(index)Where a character is, measured from the piece's position: x, y, width, height. For putting a cursor or a sparkle on it.
characterAt(x, y)The number of the character at a point (measured from the piece's position), or nil.
linkAt(x, y)The name of the [link=name] at a point (measured from the piece's position), or nil.
reveal(charactersPerSecond?, from?)Shows the text a character at a time (30 a second unless you say): a typewriter. Returns a handle with cancel(), after(fn) and wait(seconds). [pause=0.5] and [speed=10] in rich text change the pace.
skip()Shows all of the text now, and ends a reveal().
Event (a function in its script)
function revealed(index, char)reveal() showed one more character: play a blip, or wait at a full stop.
function finished()reveal() has shown the whole text.
function eachCharacter(c)Called for every character each time the text is drawn, to move or color it: c.y = math.sin(c.time * 4 + c.index) * 3. c has x, y, rotation, scale, color, alpha, visible to change, and index, count, char, line, time, since to read. It's one table used for every character, so don't keep it.

#Tiles

A grid of tiles from a tileset. Solid tiles block bodies.

Extends Group.

PropertyTypeDefault
tilesetresource""The .tileset file: a picture cut into tiles, with settings such as solid.
solidbooltrueTiles marked solid block bodies. Off makes every tile just decoration.
castShadowsboolfalseTiles marked solid block Lights that have shadows on.
animatebooltrueAnimated tiles play. Off freezes them on the frame they show.
Method
getTile(column, row)The tile number in a cell, or -1 if it's empty.
setTile(column, row, tile)Changes a cell (-1 empties it).
tileInfo(tile)The settings of a tile in the tileset (solid, name, ...).
cellAt(x, y)The cell under a point in the scene: column, row.
cellPosition(column, row)The scene position of a cell's top-left corner.
cellsWith(tile?)A list of {column, row, tile} for every painted cell (or every cell with that tile).
fill(column, row, columns, rows, tile)Sets a rectangle of cells to one tile (-1 empties them).
clear()Empties every cell.
tileAt(x, y)The tile number under a point in the scene, or -1.
isSolid(column, row)True if the cell's tile is marked solid (and solid is on).
neighbors(column, row, diagonal?)Adjacent cells as {column, row, tile}: 4, or 8 with diagonal.
cellCenter(column, row)The scene position of a cell's center.
getTileSize()The size of one cell in the scene: width, height.
getBounds()The painted area in the scene: x, y, width, height (all 0 when empty).
newPathGrid(options?)A grid for finding paths through these tiles (solid tiles are solid cells): grid:findPoints(x, y, toX, toY). It follows setTile().
setTerrain(column, row, terrain)Paints a terrain of the tileset (by name; nil erases) in a cell and re-picks the tiles of the 8 cells around it so the edges fit.
getTerrain(column, row)The name of the terrain the cell's tile belongs to, or nil.
fillTerrain(column, row, columns, rows, terrain)Paints a terrain (nil erases) in a rectangle of cells and fits the edges, also of the cells around it.
terrains()The names of the tileset's terrains.

#Background

Scrolls the pieces inside it slower or faster than the camera, for far hills, clouds and skies (parallax). It can repeat them endlessly.

Extends Group.

PropertyTypeDefault
scrollXnumber0.5How much it moves sideways with the scene when the camera moves: 1 like everything else, 0.5 half as fast (far away), 0 stays on the screen, above 1 for things in front.
scrollYnumber0.5The same, up and down.
repeatWidthnumber (px)0Draws what's inside again every this many pixels sideways, as far as the view goes (0: once). Use the width of the picture.
repeatHeightnumber (px)0Draws what's inside again every this many pixels up and down (0: once).
driftXnumber (px/s)0Slides sideways by itself at this speed, like clouds. Negative goes left.
driftYnumber (px/s)0Slides down by itself at this speed. Negative goes up.
offsetXnumber (px)0Shifts what's inside sideways. Change it from a script to scroll by hand.
offsetYnumber (px)0Shifts what's inside up or down.
leftnumber (px)noneStops scrolling its own way while the view is left of this: from there it moves with the scene (empty for no edge).
topnumber (px)noneStops scrolling its own way while the view is above this.
rightnumber (px)noneStops scrolling its own way while the view is right of this.
bottomnumber (px)noneStops scrolling its own way while the view is below this.
Method
getScroll()How far it is drawn from where it was placed, right now: x, y.

#Camera

Decides which part of the scene is on screen. Put it inside the player to follow them.

Extends Group.

PropertyTypeDefault
activebooltrueUse this camera. When several are active, the first in the scene wins.
zoomnumber12 shows everything twice as big.
smoothingnumber0How gently it catches up: 0 sticks exactly, 5 glides.
targetpiecepath""A piece to follow, wherever the camera is in the scene (empty: the camera's own position).
offsetXnumber (px)0Looks this far right of what it follows.
offsetYnumber (px)0Looks this far below what it follows.
leftnumber (px)noneDon't show anything left of this (empty for no edge).
topnumber (px)noneDon't show anything above this.
rightnumber (px)noneDon't show anything right of this.
bottomnumber (px)noneDon't show anything below this.
Method
shake(strength?, seconds?)Shakes the view: shake(6, 0.3).
follow(piece)Follows a piece (nil: back to target, or the camera's own position).
snap()Jumps straight to what it follows, without smoothing (after a teleport).
setLimits(left, top, right, bottom)Sets the edges it doesn't show past (nil for no edge).
limitTo(piece)Keeps the view inside the painted part of a Tiles piece.
makeCurrent()Makes this the camera in use, turning the others off.
getView()The part of the scene on screen: x, y, width, height.
screenToWorld(sx, sy)A point on the screen, as a point in the scene.
worldToScreen(x, y)A point in the scene, as a point on the screen.

#Light and shadow

#Light

Shines on the pieces around it. With a dark Tint in the scene it's a torch at night; on its own it makes things brighter.

Extends Group.

PropertyTypeDefault
kindenum"point"point shines out from where the piece is, as far as radius. sun lights the whole view from one side: it shines the way the piece is turned.
radiusnumber (px)200How far the light reaches.
brightnessnumber1How strong the light is: 0 is dark, 2 is twice as bright.
colorcolor{1, 1, 1, 1}The light's color.
imageresource""A picture of the light's shape, white where it shines: a beam, a window. Empty: a soft round glow.
blendenum"add"add makes what it shines on brighter. subtract makes it darker (a patch of gloom). mix swaps the light that's there for this light's color.
offboolfalseTurn this light off.
lightstags""Only lights pieces with one of these tags, and what's inside them (empty: every piece).
fromLayernumbernoneOnly lights pieces on this layer and higher (empty: no limit).
toLayernumbernoneOnly lights pieces on this layer and lower (empty: no limit).
shadowsboolfalseOccluders, and Tiles with castShadows on, block this light.
shadowColorcolor{0, 0, 0, 1}What's left of the light inside a shadow: black for nothing. A see-through color makes fainter shadows.
shadowSoftnessnumber (px)0Blurs the edges of the shadows this far. 0 keeps them sharp, and is quickest.
shadowLengthnumber (px)0How long a sun's shadows are; 0 for shadows that never end.
shadowsFromtags""Only Occluders and Tiles with one of these tags block it (empty: all of them). The tag can be on the piece the Occluder is inside.

#Occluder

Blocks light: Lights with shadows on throw a shadow behind it. Put it inside a piece to fit that piece's Sprite or Shape.

Extends Group.

PropertyTypeDefault
shapeenum"auto"auto fits the Sprites and Shapes inside it or, when it has none, the ones in the piece it is inside.
widthnumber (px)32Rectangle width.
heightnumber (px)32Rectangle height.
radiusnumber (px)16Circle radius.
pointspoints{0, -16, 16, 16, -16, 16}Corner points x1, y1, x2, y2, ... of the outline.
offboolfalseLet light through.

#Tint

Colors the whole scene (not the on-screen UI): dark blue for night, orange for sunset. Lights shine on top of it. The first Tint in the scene wins.

Extends Piece.

PropertyTypeDefault
colorcolor{0.35, 0.4, 0.6, 1}Every piece's colors are multiplied by this: white changes nothing, black hides everything that no light reaches.
offboolfalseTurn the tint off.
fromLayernumbernoneOnly tints pieces on this layer and higher (empty: no limit).
toLayernumbernoneOnly tints pieces on this layer and lower (empty: no limit).

#Bodies and zones

#Body

Solid. motion: still (walls), scripted (moved with move()) or physics (simulated). Takes its shape from a Sprite or Shape inside it.

Extends Group. Uses the physics2d (Box2D) module.

PropertyTypeDefault
motionenum"scripted"still: moves only when a script sets x/y. scripted: moved by move(). physics: simulated.
shapeenum"auto"auto fits the Sprites and Shapes inside. capsule has round ends. none: Hitboxes only.
widthnumber (px)32Rectangle or capsule width.
heightnumber (px)32Rectangle or capsule height.
radiusnumber (px)16Circle radius.
pointspoints{0, -16, 16, 16, -16, 16}Corner points x1, y1, x2, y2, ... (up to 8 corners; a dent is filled in).
vxnumber (px/s)0Horizontal speed (px/s).
vynumber (px/s)0Speed down (negative is up). Scripted: what move() goes by. Physics: its speed now.
spinangle (°/s)0°How fast it turns, in degrees a second (clockwise is positive): 360 is a whole turn every second. Scripted: move() turns it this fast.
slopeangle (°)2578.31°The steepest surface that still counts as ground, in degrees: move() walks up it without sliding back.
massnumber (kg)1Kilograms. A scripted body pushes physics bodies by its mass against theirs.
frictionnumber0.3How much it grips what it touches: 0 is ice.
bouncenumber0How much it bounces: 0 none, 1 forever.
gravityScalenumber1How strongly gravity pulls it: 1 is normal, 0 floats, -1 falls up.
dragnumber0Air resistance: slows its movement down.
spinDragnumber0Slows its turning down.
fixedRotationboolfalseNever tip over or spin.
bulletboolfalseContinuous collision against moving bodies, for small fast objects.
asleepboolfalseAt rest until touched. Physics bodies sleep when they stop.
passThroughtags""Tags of things it doesn't bump into, like "ghost, pickup" ("tiles" for solid tiles).
Method
move()Moves by vx, vy for this step: slides along walls, climbs slopes, rides platforms, pushes physics bodies.
moveBy(dx, dy)Moves by an offset and stops at the first thing in the way; returns what it hit, or nil.
onGround()True if the last move ended standing on something.
onWall()True if the last move ran into a wall.
onCeiling()True if the last move ran into a ceiling.
applyImpulse(ix, iy, x?, y?)Instant change of velocity by impulse / mass. At a point, also spins.
applyForce(fx, fy, x?, y?)Force for this step; call every physicsUpdate. At its center or a point.
applyTorque(torque)Turns it steadily for this step (physics bodies).
applyAngularImpulse(impulse)A sudden twist (physics bodies).
push(ix, iy)The same as applyImpulse(ix, iy).
wake()Wakes a sleeping physics body.
grab(x, y, strength?)Holds it by a scene point for dragTo(); drop() releases with momentum.
dragTo(x, y)Moves the grabbed point towards x, y.
drop()Lets go after grab(); a physics body keeps its speed.
touching(tagOrPiece)The first body or zone with a tag (or that piece) touching this one, or nil.
isTouching(other)True if it touches a piece (a body, zone or Tiles) or anything with a tag.
contacts()Current contacts: {piece, x, y, nx, ny, impulse}.
touchingTile(setting)The settings of a touching tile that has this setting (like "damage"), or nil.
getSize()The size of the box around its shapes: width, height.
Event (a function in its script)
function hit(other, contact)Started touching a body or solid tiles. contact: x, y, nx, ny (from other to this body), impulse.
function entered(zone)It went into a zone.
function exited(zone)It left a zone.

#Joint

Connects body a to body b, or to its own position.

Extends Group. Uses the physics2d (Box2D) module.

PropertyTypeDefault
kindenum"pin"pin, weld, rope, spring, distance, slider (x axis), wheel (y axis spring) or mouse.
apiecepath""The body it holds.
bpiecepath""The body it connects a to (empty: the place where the Joint is).
lengthnumber (px)0How far apart; 0 uses the distance when the joint is made.
springboolfalseSpringy: a pin or slider pulls back to where it started, a weld wobbles.
stiffnessnumber (Hz)4How stiff the spring is: wobbles per second.
dampingnumber0.5How quickly the spring stops wobbling: 1 doesn't overshoot.
motorboolfalseDrive it: turn a pin or wheel, or move a slider, at motorSpeed.
motorSpeednumber90Degrees a second (pin, wheel) or pixels a second (slider, distance).
motorStrengthnumber100000The most torque (pin, wheel) or force (slider, distance) the motor uses.
limitboolfalseKeep a pin between minAngle and maxAngle, or a slider or wheel between lower and upper.
minAngleangle (°)-2578.31°The furthest a pin turns anticlockwise, in degrees.
maxAngleangle (°)2578.31°The furthest a pin turns clockwise, in degrees.
lowernumber (px)-50The furthest a slider or wheel goes back.
uppernumber (px)50The furthest a slider or wheel goes forward.
strengthnumber0The most force a mouse joint pulls with; 0 is plenty for the body's mass.
collideboolfalseThe two bodies still bump into each other.
breakForcenumber0Breaks (and sends broke) when pulled harder than this; 0 never breaks.
Method
getAngle()How far a pin has turned, in degrees.
getTranslation()How far a slider has slid (pixels).
getLength()How far apart a rope, spring or distance joint's ends are.
getSpeed()How fast a pin turns (degrees a second) or a slider slides (pixels a second).
getForce()How hard the joint pulls now.
getTorque()How hard the joint twists now.
isBroken()True once breakForce broke it.
Event (a function in its script)
function broke()It was pulled harder than breakForce and let go.

#Walkable

A polygon that says where things can walk. smitten.paths.findPath() finds a way through all the Walkable pieces in the scene.

Extends Group.

PropertyTypeDefault
pointspoints{-100, -60, 100, -60, 100, 60, -100, 60}Corner points x1, y1, x2, y2, ... in order round the shape. Any number of corners; dents are fine.

activebooltrueCounts for paths. Turn it off to close an area (or fill a hole) for a while.

#On-screen UI

widthnumber (px)160Width (ignored with fill).
heightnumber (px)40Height (ignored with fill).
grownumber0Inside a Row or Column: its share of the room left over (two pieces with 1 split it in half). 0 keeps its own size.
visiblebooltrueShow this piece and everything inside it.
opacitynumber10 is invisible, 1 is solid.
Method

isHovered()True while the mouse is over it.
