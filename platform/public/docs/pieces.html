Pieces

Each piece has its own properties plus its base type's. In its own script: x = 10, move(), function pressed() end. On another piece: other.x, other:move(), other:on("pressed", fn). Angles are radians in code, degrees in the Inspector.

#Basic

#Piece

Everything in a scene is a piece. Pieces nest: a piece's children belong to it.

A base for other types; not added itself.

PropertyTypeDefault
pausablebooltrueStops while the game is paused. Off: this piece and its children keep running (pause menus).
Method
find(path)A child by name, or a deeper piece by path ("UI/Score"); nil if there isn't one.
findDeep(name)The first piece with this name anywhere inside this one.
findChildOfType(type)The first child of a type ("Sprite"), or nil.
isA(type)True if the piece is of a type, or a type made from it.
add(piece)Adds a piece as the last child; returns it.
remove()Takes the piece out of its parent now, without destroying it.
spawn(sceneOrType, properties?)Makes a piece from a scene file or type and adds it as a child.
destroy()Removes the piece and everything inside it at the end of the frame.
tag(name)Adds a tag.
untag(name)Takes a tag away.
hasTag(name)True if the piece has the tag.
hasAnyTag(tags)True if the piece has any of the tags in a comma-separated list: hasAnyTag("enemy, spikes").
is(tagOrType)True if the piece has the tag or is of the type: other:is("enemy"), other:is("Body").
on(event, fn)Calls fn(...) on an event. Returns a handle with :off().
emit(event, ...)Fires an event: calls the script's function of that name and every listener.
getPath()The piece's path from the scene's root, like "Level/Player".
isAlive()True while the piece is in the running scene and not destroyed.
Event (a function in its script)
function ready(...)The piece and its children joined the scene. The scene root gets go()'s extra values.
function update(dt)Every frame. dt is the time since the last frame, in seconds.
function physicsUpdate(dt)60 times a second, before bodies move. Use it for movement.
function draw()Draw extra things on top of the piece, in its own coordinates.
function removed()The piece is leaving the scene.

#Group

A piece with a position. Use it to hold other pieces (they move with it) or to run a script.

Extends Piece.

PropertyTypeDefault
xnumber (px)0Position, measured from the parent.
ynumber (px)0Position, measured from the parent. y grows downwards.
rotationangle0°Turn, clockwise: radians in code, degrees in the inspector.
scaleXnumber1Width multiplier. Negative mirrors it.
scaleYnumber1Height multiplier. Negative flips it.
visiblebooltrueShow this piece and everything inside it.
tintcolor{1, 1, 1, 1}Multiplies the colors of this piece and everything inside it.
layerint0Higher layers are drawn on top. Pieces on the same layer draw in scene order.
Method
worldPosition()Where the piece is in the scene (not measured from its parent): x, y.
setWorldPosition(x, y)Moves the piece to a place in the scene.
toWorld(x, y)A point measured from this piece, as a point in the scene.
fromWorld(x, y)A point in the scene, measured from this piece.
lookAt(x, y)Turns the piece to face a point in the scene.
distanceTo(pieceOrX, y?)Distance in pixels to another piece or a point.
angleTo(pieceOrX, y?)Angle in radians towards another piece or a point.
moveToward(x, y, distance)Moves at most distance pixels towards a point; true once it's there.
translate(dx, dy)Moves the piece by an offset.

#Timer

Counts down and calls tick().

Extends Piece.

PropertyTypeDefault
secondsnumber (s)1Time between ticks.
runningboolfalseCounting. On in the scene file means it starts with the scene.
loopbooltrueKeep ticking; off ticks once and stops.

timeLeft: Seconds until the next tick.

Method
start(seconds?)Starts (or restarts) the countdown.
stop()Stops the countdown.
Event (a function in its script)
function tick()The countdown reached zero.

#Things you see

#Sprite

Draws a picture, or an animation from a .sprite file or a sprite sheet.

Extends Group.

PropertyTypeDefault
imageresource""A picture (.png, .jpg) or a .sprite file with frames and animations.
animationanimation""The animation to play, from the .sprite file.
playingbooltruePlay the animation.
speednumber1Animation speed: 2 is twice as fast.
frameint0The frame shown, counting from 0.
columnsint1For a sprite sheet without a .sprite file: frames across.
rowsint1For a sprite sheet without a .sprite file: frames down.
centeredbooltrueCenter the picture on the piece's position (a .sprite file's origin wins).
flipXboolfalseMirror left to right.
flipYboolfalseMirror top to bottom.
Method
play(name?, restart?)Plays an animation, or resumes the current one. restart: from the first frame.
pause()Stops the animation where it is; play() continues it.
stop()Stops the animation and goes back to its first frame.
hasAnimation(name)True if the .sprite file has an animation with this name.
animations()The names of the .sprite file's animations, sorted.
getSize()Width and height of one frame, in pixels.
getRect()The rectangle the picture covers, in the piece's own coordinates: x, y, width, height.
Event (a function in its script)
function finished(animation)A non-looping animation reached its last frame.

#Shape

Draws a rectangle, circle, polygon or line. Good for prototypes, effects and games without art.

Extends Group.

PropertyTypeDefault
shapeenum"rectangle"What to draw.
widthnumber (px)64Rectangle width.
heightnumber (px)64Rectangle height.
radiusnumber (px)32Circle radius.
cornerRadiusnumber (px)0Rounds the rectangle's corners.
pointspoints{0, -32, 32, 32, -32, 32}Corner points x1, y1, x2, y2, ...
colorcolor{0.36, 0.55, 0.95, 1}Fill or line color.
filledbooltrueFill the shape; off draws only its outline.
lineWidthnumber (px)2Outline and line thickness.
centeredbooltrueCenter the rectangle on the piece's position.
Method
getRect()The rectangle the shape covers, in the piece's own coordinates: x, y, width, height.

#Text

Words in the game world, like a sign or a damage number. For scores and menus, use Label.

Extends Group.

PropertyTypeDefault
texttext"Text"What it says.
fontresource""A .ttf/.otf font file, "pixel" for the built-in pixel font, or empty for the default font.
sizeint (px)16Font size.
colorcolor{1, 1, 1, 1}Text color.
alignenum"center"Lines up the text around the piece's position.
wrapnumber (px)0Wrap lines longer than this; 0 never wraps.

#Tiles

A grid of tiles from a tileset. Solid tiles block bodies.

Extends Group.

PropertyTypeDefault
tilesetresource""The .tileset file: a picture cut into tiles, with settings such as solid.
solidbooltrueTiles marked solid block bodies. Off makes every tile just decoration.
Method
getTile(column, row)The tile number in a cell, or -1 if it's empty.
setTile(column, row, tile)Changes a cell (-1 empties it).
tileInfo(tile)The settings of a tile in the tileset (solid, name, ...).
cellAt(x, y)The cell under a point in the scene: column, row.
cellPosition(column, row)The scene position of a cell's top-left corner.
cellsWith(tile?)A list of {column, row, tile} for every painted cell (or every cell with that tile).
fill(column, row, columns, rows, tile)Sets a rectangle of cells to one tile (-1 empties them).
clear()Empties every cell.
tileAt(x, y)The tile number under a point in the scene, or -1.
isSolid(column, row)True if the cell's tile is marked solid (and solid is on).
neighbors(column, row, diagonal?)Adjacent cells as {column, row, tile}: 4, or 8 with diagonal.
cellCenter(column, row)The scene position of a cell's center.
getTileSize()The size of one cell in the scene: width, height.
getBounds()The painted area in the scene: x, y, width, height (all 0 when empty).

#Camera

Decides which part of the scene is on screen. Put it inside the player to follow them.

Extends Group.

PropertyTypeDefault
activebooltrueUse this camera. When several are active, the first in the scene wins.
zoomnumber12 shows everything twice as big.
smoothingnumber0How gently it catches up: 0 sticks exactly, 5 glides.
targetpiecepath""A piece to follow, wherever the camera is in the scene (empty: the camera's own position).
offsetXnumber (px)0Looks this far right of what it follows.
offsetYnumber (px)0Looks this far below what it follows.
leftnumber (px)noneDon't show anything left of this (empty for no edge).
topnumber (px)noneDon't show anything above this.
rightnumber (px)noneDon't show anything right of this.
bottomnumber (px)noneDon't show anything below this.
Method
shake(strength?, seconds?)Shakes the view: shake(6, 0.3).
follow(piece)Follows a piece (nil: back to target, or the camera's own position).
snap()Jumps straight to what it follows, without smoothing (after a teleport).
setLimits(left, top, right, bottom)Sets the edges it doesn't show past (nil for no edge).
limitTo(piece)Keeps the view inside the painted part of a Tiles piece.
makeCurrent()Makes this the camera in use, turning the others off.
getView()The part of the scene on screen: x, y, width, height.
screenToWorld(sx, sy)A point on the screen, as a point in the scene.
worldToScreen(x, y)A point in the scene, as a point on the screen.

#Particles

Sprays particles: smoke, sparks, dust, rain, explosions.

Extends Group.

PropertyTypeDefault
emittingbooltrueMake new particles.
ratenumber (/s)30Particles per second.
burstboolfalseMake one burst of rate particles, then stop.
lifetimenumber (s)1How long each particle lives.
imageresource""The particle picture; empty draws soft dots.
speednumber (px/s)100Starting speed.
speedRandomnumber0.5How much the speed varies (0 to 1).
directionangle-90°Direction particles fly in.
spreadangle28.65°How far directions vary either side.
gravityXnumber (px/s²)0Constant pull, sideways.
gravityYnumber (px/s²)0Constant pull, down.
sizeStartnumber (px)8Size when born.
sizeEndnumber (px)2Size when it fades.
colorStartcolor{1, 0.85, 0.4, 1}Color when born.
colorEndcolor{1, 0.3, 0.1, 0}Color when it fades.
followPieceboolfalseParticles move with the piece instead of staying where they were born.
Method
emit(count)Makes count particles right now. emit("event", ...) still fires an event.
start()Starts making particles (a burst makes its particles again).
stop()Stops making particles; the ones already out live on.
clear()Removes every particle now.
restart()Clears every particle and starts again.
getCount()How many particles are out now.
Event (a function in its script)
function finished()The last particle is gone and no more are coming (after a burst or stop()). Good for destroy().

#Bodies and zones

#Body

Something solid: it bumps into other bodies and solid tiles. Pick how it moves: still (walls and floors), scripted (players and enemies you move in code) or physics (crates that fall and tumble). Put a Sprite or Shape inside it and its shape fits itself.

Extends Group.

PropertyTypeDefault
motionenum"scripted"Still never moves on its own; scripted moves when its script calls move(); physics falls, bounces and gets pushed.
shapeenum"auto"Auto fits the Sprites and Shapes inside it. None uses only its Hitboxes. Physics turns shapes with the Body; scripted Bodies and Zones collide as if unturned.
widthnumber (px)32Rectangle width.
heightnumber (px)32Rectangle height.
radiusnumber (px)16Circle radius.
vxnumber (px/s)0Speed sideways, used by move() (scripted) or physics.
vynumber (px/s)0Speed down, used by move() (scripted) or physics.
slopeangle45°The steepest surface that still counts as ground.
massnumber (kg)1How heavy it is.
frictionnumber0.3How much it grips what it touches.
bouncenumber0How much it bounces: 0 none, 1 forever.
gravitynumber1How strongly gravity pulls it; 0 floats.
dragnumber0Air resistance.
fixedRotationboolfalseNever tip over or spin.
passThroughtags""Tags of things it doesn't bump into, like "ghost, pickup".
Method
move()Moves by vx, vy for this step, sliding along walls and floors (scripted bodies).
moveBy(dx, dy)Moves by an offset and stops at the first thing in the way; returns what it hit, or nil.
onGround()True if the last move ended standing on something.
onWall()True if the last move hit a wall.
onCeiling()True if the last move hit a ceiling.
touching(tagOrPiece)The first body or zone with a tag (or that piece) touching this one, or nil.
touchingTile(setting)The settings of a touching tile that has this setting (like "damage"), or nil.
push(ix, iy)A sudden kick, like a jump or a hit (physics bodies).
applyForce(fx, fy)Pushes steadily this frame (physics bodies).
getSize()The size of its shape: width, height.
Event (a function in its script)
function hit(other)It bumped into another body or solid tiles.
function entered(zone)It went into a zone.
function exited(zone)It left a zone.

#Zone

An area that notices bodies and zones going in and out: pickups, checkpoints, danger. Nothing bumps into it.

Extends Group.

PropertyTypeDefault
shapeenum"auto"Auto fits the Sprites and Shapes inside it.
widthnumber (px)32Rectangle width.
heightnumber (px)32Rectangle height.
radiusnumber (px)16Circle radius.
detectstags""Only notices things with one of these tags (empty: everything).
activebooltrueNotice things going in and out.
Method
inside()A list of the bodies and zones inside it now.
touching(tagOrPiece)The first body or zone with a tag (or that piece) inside it, or nil.
Event (a function in its script)
function entered(other)A body or zone came in.
function exited(other)A body or zone left.

#Hitbox

An extra collision shape for the Body or Zone it's inside, for shapes auto can't make: an L shape, a sword's reach.

Extends Group. Goes inside a Body or Zone.

PropertyTypeDefault
shapeenum"rectangle"Shapes move and scale with their piece. They turn with it only for physics (Bodies moved by physics, and what they land on).
widthnumber (px)32Rectangle width.
heightnumber (px)32Rectangle height.
radiusnumber (px)16Circle radius.
offboolfalseTurn this shape off.

#Joint

Connects two physics bodies: a pin, a rope, a spring or a weld.

Extends Group. Uses the physics2d (Box2D) module.

PropertyTypeDefault
kindenum"pin"How the bodies are connected.
apiecepath""The first body.
bpiecepath""The second body (empty: pinned in place).
lengthnumber (px)0Rope and spring length; 0 uses the distance when the scene starts.
stiffnessnumber4Spring stiffness (wobbles per second).
dampingnumber0.5How quickly a spring stops wobbling.

#On-screen UI

#UI

The base of UI pieces: a rectangle on the screen, placed from a corner, an edge or the center.

Extends Piece. A base for other types; not added itself.

PropertyTypeDefault
anchorenum"topLeft"What x and y are measured from. fill covers the screen or the parent UI piece.
xnumber (px)0Distance in from the anchor.
ynumber (px)0Distance in from the anchor.
widthnumber (px)160Width (ignored with fill).
heightnumber (px)40Height (ignored with fill).
visiblebooltrueShow this piece and everything inside it.
opacitynumber10 is invisible, 1 is solid.
Method
getRect()Where it is on the screen now: x, y, width, height.
isHovered()True while the mouse is over it.
Event (a function in its script)
function hovered()The pointer came over it (not Labels).
function unhovered()The pointer left it.

#Label

Words on the screen: scores, timers, titles, dialog.

Extends UI.

PropertyTypeDefault
texttext"Label"What it says. Change it from a script: text = Score: {score}.
fontresource""A .ttf/.otf font, "pixel", or empty for the default font.
sizeint (px)20Font size.
colorcolor{1, 1, 1, 1}Text color.
alignenum"left"Lines up the text inside its rectangle.
valignenum"top"Lines up the text top to bottom.
outlineboolfalseA dark outline around the text.

#Button

A button to click or tap. Its script gets pressed().

Extends UI.

PropertyTypeDefault
texttext"Button"The button's words.
fontresource""A font, or empty for the default.
sizeint (px)18Font size.
colorcolor{0.25, 0.47, 0.95, 1}Background color.
textColorcolor{1, 1, 1, 1}Text color.
cornerRadiusnumber (px)6Rounds the corners.
disabledboolfalseCan't be pressed; drawn faded.
autofocusboolfalseHas keyboard focus when the scene starts.
Method

isFocused()True while it has the keyboard focus.
isDown()True while it's held down.
Event (a function in its script)
function pressed()The button was clicked, tapped, or pressed with accept while focused.

#Panel

A colored box behind other UI: a dialog, a HUD background.

Extends UI.

PropertyTypeDefault
colorcolor{0.08, 0.09, 0.12, 0.85}Fill color.
cornerRadiusnumber (px)8Rounds the corners.
borderColorcolor{1, 1, 1, 0.15}Outline color.
borderWidthnumber (px)1Outline thickness; 0 for none.
Event (a function in its script)
function pressed()The panel was clicked or tapped (not on a button inside it).

#Picture

A picture on the screen: an icon, a portrait, a logo.

Extends UI.

PropertyTypeDefault

fitenum"contain"How the picture fills the rectangle.
colorcolor{1, 1, 1, 1}Tint.
Event (a function in its script)

#Bar

A bar that fills up: health, loading, a countdown.

Extends UI.

PropertyTypeDefault

maxnumber100The value when full.
colorcolor{0.3, 0.8, 0.45, 1}Fill color.

#Sound

#Sound

Plays a sound or music: a .wav, .ogg or .mp3 file, or a .sfx or .song made in Smitten.

Extends Piece.

PropertyTypeDefault
soundresource""The sound file.
autoplayboolfalsePlay when the scene starts.
loopboolfalseStart again at the end.
volumenumber1Loudness, 0 to 1.
pitchnumber11 is normal; 2 is an octave up.
Method
play()Plays and returns the LÖVE Source. Calling it while playing starts another copy (not for .song).
stop()Stops every copy.
pause()Pauses.
resume()Continues after pause().
isPlaying()True while it's playing.
fadeIn(seconds, volume?)Plays from silence up to its volume (or volume) over some seconds.
fadeOut(seconds)Fades to silence, then stops; volume goes back to what it was.
seek(seconds)Jumps to a time in the sound.
tell()Where it's playing, in seconds.
getDuration()How long the sound is, in seconds.
Event (a function in its script)
function finished()The sound reached its end (not when looping).
