Sharing and publishing

#Publishing

Publish in the top bar puts your game on the sharing site, where anyone can play it in their browser with a link. You'll need an account: sign up with a username and password, or with Hack Club.

Give the game a title, a short description and a thumbnail, and publish. Publishing again from the same project updates the same game, so its link never changes. A game's page shows who made it, how long it took (if they connected Hackatime), and buttons to Play, Remix (open your own copy in the editor) and Report it.

A published game can also have leaderboards: shared high scores, shown under the game on its page.

#Exporting

Project › Export (Ctrl+E) makes files you can take anywhere:
Web game (zip)The game and the player, with only the engine modules it uses. Upload it to itch.io as an HTML game, or to any website
Project (zip)Every file of the project, to back it up or open it in Smitten somewhere else

#Share links

Project › Copy share link puts a whole small project (up to 32 KB compressed) into a link. Whoever opens it gets their own copy in the editor to play and change. Nothing is uploaded, so it works for quick experiments; for bigger games, publish or export.
