UI

UI pieces are drawn on top of the game, in screen pixels, and cameras don't move them: Label (words), Button, Bar (health, loading), Panel (a box behind other UI) and Picture. Put them anywhere in the scene; a UI piece inside another is laid out inside it.

#Layout

A UI piece is a rectangle placed from an anchor: a corner, an edge, the center, or fill (the whole screen, or the UI piece it's inside). x and y are the distance in from the anchor, so with bottomRight, x = 16, y = 16 is 16 pixels in from the bottom-right corner, whatever the screen size. Every property can change while the game runs:

Message.anchor = "center"
Message.text = "Level complete!"
tween(Message, 0.3, { opacity = 1, y = 0 })

getRect() is where a UI piece is on the screen now (x, y, width, height). visible and opacity hide or fade it and everything inside it.

#Labels and bars

function update(dt)
  find("HUD/Score").text = `Score: {game.score}`
  find("HUD/Health").value = hp      -- a Bar from min to max
end

#Buttons

A Button's script gets pressed() when it's clicked or tapped. Pictures and Panels get it too.

-- On a "Play" button
function pressed()
  go("scenes/level1.scene")
end

Other scripts listen with on: find("UI/Quit"):on("pressed", function() ... end). In a Button's script, pressed is the button's event, so read input there with smitten.input.pressed(action).
disabledCan't be pressed; drawn faded
isHovered()The pointer is over it
isDown()It's held down
hovered(), unhovered()Events: the pointer came over it, left it
smitten.mouse.isOverUI()The pointer is over a button or panel (so a click there doesn't also shoot)

#Menus with the keyboard and gamepads

Turn on a Button's autofocus and it has the focus when the scene starts: the arrow keys, the d-pad and the stick (the up, down, left and right actions) move the focus to the nearest button that way, and accept (Enter, Space, gamepad A) presses it. The focused button is outlined. focus() moves the focus from a script; isFocused() tells. Clicking a button moves the focus to it.

Without a focused button, the arrow keys are the game's alone, so a Restart button in a game's HUD doesn't steal them.

#Pause menus

UI answers clicks and the keyboard while the game is paused. For a pause menu's script to keep running, put the menu inside a piece whose pausable is off; see Pausing.

#Drawing on UI

A UI piece's draw() draws in screen pixels, from its rectangle's top-left corner: see Drawing.
