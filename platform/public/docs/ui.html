UI

UI pieces draw on top of the game, in screen pixels, and the camera doesn't move them, which suits scores, health bars and menus. There are seven: Label (text), Button, Bar (health, progress), Panel (a box behind other UI), Picture, and for touch screens TouchStick and TouchButton (Input: Touch). A UI piece inside another is laid out inside it.

#Layout

Each UI piece is placed from an anchor: a corner, an edge, the center, or fill (the whole screen, or the whole of the UI piece it's inside). x and y are the distance in from that anchor. With the anchor bottomRight and x, y at 16, a piece sits 16 pixels in from the bottom-right corner on any screen size.

Every setting can change while the game runs:

Message.text = "Level complete!"
tween(Message, 0.3, { opacity = 1 })

getRect() returns where a UI piece is on the screen right now, and visible and opacity hide or fade it along with everything inside it.

#Buttons

When a Button is clicked or tapped, its script's pressed() runs (Pictures and Panels get it too):

-- On a "Play" button
function pressed()
  go("scenes/level1.scene")
end

In a Button's own script, pressed means that event, so read input there with smitten.input.pressed(...).
disabledCan't be pressed; drawn faded
isHovered(), isDown()The pointer is over it; it's held down
hovered(), unhovered()Events when the pointer arrives and leaves
smitten.mouse.isOverUI()The pointer is over any button or panel

#Menus for keyboards and gamepads

Turn on a Button's autofocus and it has the focus when the scene starts. The arrow keys, d-pad and stick then move the focus to the nearest button in that direction, and Enter, Space or gamepad A press it. Clicking a button also focuses it, and focus() moves the focus from a script. While no button has focus, the arrow keys go to the game as usual.

UI keeps working while the game is paused, which is what pause menus need (Pausing).

xnumber (px)0Distance in from the anchor.
ynumber (px)0Distance in from the anchor.
widthnumber (px)160Width (ignored with fill).
heightnumber (px)40Height (ignored with fill).
visiblebooltrueShow this piece and everything inside it.
opacitynumber10 is invisible, 1 is solid.
Method

isHovered()True while the mouse is over it.
Event (a function in its script)

function unhovered()The pointer left it.

#Label

A Label's words can do everything on the Text page: tags for colors, sizes and effects inside the text (turn on rich), an outline or a shadow, shrinking to fit (fit), typing themselves out (reveal()), and links that call linkPressed(name).

PropertyTypeDefault
texttext"Label"What it says. Change it from a script: text = Score: {score}.
fontresource""A .ttf/.otf font, "pixel", or empty for the default font.
sizeint (px)20Font size.
colorcolor{1, 1, 1, 1}Text color.
alignenum"left"Lines up the text inside its rectangle. justify stretches wrapped lines to the same width.
valignenum"top"Lines up the text top to bottom.
wrapByenum"word"Where a line too long for the rectangle is broken: between words, after any character (for writing without spaces, like Japanese), or not at all.
fitenum"none"shrink makes the text smaller until it fits inside the rectangle.
richboolfalseReads tags in the text: [b]bold[/b], [color=red]red[/color], [wave]wavy[/wave] and more (see the Text page of the docs). Type [[ for a real square bracket.
outlineboolfalseA dark outline around the text.
fontBoldresource""The font file for [b]bold[/b] words. Empty: the font is made thicker instead.
fontItalicresource""The font file for [i]italic[/i] words. Empty: the font is slanted instead.
lineHeightnumber1How far apart lines are: 1 is the font's own spacing, 1.5 leaves half a line between them.
letterSpacingnumber (px)0Extra room between letters (negative squeezes them together).
outlineWidthnumber (px)0How thick the outline is. 0 keeps it one screen pixel thin.
outlineColorcolor{0, 0, 0, 0.8}The outline's color.
shadowboolfalseA shadow behind the text.
shadowColorcolor{0, 0, 0, 0.5}The shadow's color.
shadowXnumber (px)2How far right the shadow falls (negative: left).
shadowYnumber (px)2How far down the shadow falls (negative: up).
visibleCharactersint-1How many characters show, counted from the start: 0 shows nothing, -1 shows them all. reveal() counts this up for a typewriter effect.
visibleRationumber1How much of the text shows: 0 is nothing, 0.5 the first half, 1 all of it. Tween it to reveal the text smoothly.
Method
measure()How big the text is as it's laid out now: width, height.
lineCount()How many lines the text takes.
characterCount()How many characters the text has (tags and line breaks don't count).
characterRect(index)Where a character is, measured from the label's top-left corner: x, y, width, height. For putting a cursor or a sparkle on it.
characterAt(x, y)The number of the character at a point (measured from the label's top-left corner), or nil.
linkAt(x, y)The name of the [link=name] at a point (measured from the label's top-left corner), or nil.
reveal(charactersPerSecond?, from?)Shows the text a character at a time (30 a second unless you say): a typewriter. Returns a handle with cancel(), after(fn) and wait(seconds). [pause=0.5] and [speed=10] in rich text change the pace.
skip()Shows all of the text now, and ends a reveal().
Event (a function in its script)
function revealed(index, char)reveal() showed one more character: play a blip, or wait at a full stop.
function finished()reveal() has shown the whole text.
function eachCharacter(c)Called for every character each time the text is drawn, to move or color it: c.y = math.sin(c.time * 4 + c.index) * 3. c has x, y, rotation, scale, color, alpha, visible to change, and index, count, char, line, time, since to read. It's one table used for every character, so don't keep it.
function linkPressed(name)A [link=name] in the text was clicked or tapped.

#TouchStick

A stick for a thumb: it pushes input actions like a gamepad's stick. Input: Touch shows how to lay out touch controls.

PropertyTypeDefault
leftActionaction"left"The action it pushes when the thumb goes left (none: it pushes nothing that way).
rightActionaction"right"The action it pushes when the thumb goes right.
upActionaction"up"The action it pushes when the thumb goes up.
downActionaction"down"The action it pushes when the thumb goes down.
playerint0Whose actions it pushes: 2 for player 2. 0 takes the player of the piece it's inside, or player 1.
modeenum"fixed"fixed stays in the middle of its rectangle. floating appears where the thumb lands, anywhere in the rectangle. follow does too, and is dragged along when the thumb goes further than the radius.
radiusnumber (px)60How far the thumb goes for a full push; also the size of the stick's circle.
deadzonenumber0.2How much of the radius near the middle counts as not pushed at all (0.2 is a fifth).
showenum"touch"touch draws it on phones and tablets, and on any screen once a finger touches it. always draws it everywhere, and the mouse can work it. never keeps it invisible; fingers still work it.
colorcolor{1, 1, 1, 0.25}The color of the stick's circle (or a tint for its image).
knobColorcolor{1, 1, 1, 0.6}The color of the knob under the thumb (or a tint for its image).
imageresource""A picture for the stick's circle, instead of the drawn one.
knobImageresource""A picture for the knob, instead of the drawn one.
Method
getValue()Where the stick is pushed: x, y from -1 to 1 (0, 0 when no finger is on it).
isActive()True while a finger is on the stick.
Event (a function in its script)
function pressed()A finger landed on the stick.
function released()The finger let go of the stick.
