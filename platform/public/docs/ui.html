UI

UI pieces draw on top of the game, in screen pixels. The camera does not move them. Because of this, UI pieces are good for scores, health bars and menus.
To showLabel (text), Bar (health, progress), Panel (a box behind other UI), Picture
To workButton, Slider, Checkbox (a box to tick, a switch, or one item in a choice), TextInput (a box to type in)
To lay outRow, Column, Grid, Scroll (a list that is longer than the screen)
For touch screensTouchStick and TouchButton (Input: Touch)

These pieces are building blocks. A settings screen, an inventory or a chat box is a set of these pieces. There is an example below. If a UI piece is inside a different UI piece, Smitten lays it out inside that piece.

#Layout

Smitten puts each UI piece relative to an anchor. The anchor is a corner, an edge, the center, or fill. fill is all of the screen, or all of the UI piece that the piece is inside. x and y are the distance in from the anchor. For example, set the anchor to bottomRight. Then set x and y to 16. On all screen sizes, the piece is 16 pixels in from the bottom-right corner.

You can change each property while the game runs:

Message.text = "Level complete!"
tween(Message, 0.3, { opacity = 1 })

getRect() gives the position of a UI piece on the screen at this time. visible hides a UI piece and all the pieces in it. opacity fades a UI piece and all the pieces in it.

#Laying things out

It takes a long time to put each button of a menu in its position. A Row, a Column or a Grid puts the UI pieces that are directly in it in a line. It uses the order of the pieces in the Scene panel:
RowLeft to right
ColumnTop to bottom
GridIn columns, one row after the other: for example, an inventory or a level select screen
ScrollTop to bottom (or left to right), in a window that scrolls

In one of these containers, a piece keeps its width and height. The container does not use the anchor, x and y of the piece. To move the piece, drag it up or down in the Scene panel. The container itself uses its own anchor. Because of this, a Column with the anchor center is a menu in the middle of the screen, on all screen sizes.

PropertyWhat it does
gapThe space between one piece and the next piece
paddingThe space between the edges of the container and the pieces
alignItemsThe position across the line of pieces: start, center, end, or stretch. stretch makes all the pieces as tall as the Row (or as wide as the Column)
justifyThe position along the line of pieces, when there is space that the pieces do not use: start, center, end, or spaceBetween. spaceBetween puts the pieces from one edge to the other edge, with equal spaces
width, height0 makes the container fit the pieces in it. If you set a different value, the container has that size, independent of the pieces in it
grow (on a piece in the container)The part of the unused space in a Row or Column that the piece gets. If one piece has grow 1, it gets all the space. If two pieces have grow 1, they share it

You can put containers in containers. For example, a Column of Rows is a form, with a Label and a Slider in each Row. Containers do not draw anything. For a background, put the container in a Panel. A container calculates its layout again only when a piece in it changes. Because of this, a big menu that does not change does not make the game slower.

Smitten also puts pieces that you make while the game runs in the line:

-- On a Column: make one Button for each saved game
function ready()
  for i, name in ipairs(load("saves", {})) do
    local b = self:spawn("Button", { text = name })
    b:on("clicked", function() go("scenes/game.scene", { save = name }) end)
  end
end

#Scroll

A Scroll is a window on a list that is longer than the Scroll. It puts the pieces in it one below the other, as a Column does. Each piece is as wide as the Scroll. If you set direction to horizontal, the Scroll puts the pieces from left to right, as a Row does. Then each piece is as tall as the Scroll. The Scroll shows the part of the list that fits in it.

These scroll the list:

  • the mouse wheel.
  • a drag or a flick with a finger or the mouse.
  • the keyboard focus: if the focus moves to a piece that you cannot see, the Scroll scrolls to show that piece.

For a grid that scrolls, put a Grid in the Scroll.

List.scrollY = 0                 -- go back to the top
List:scrollTo(List.Item20)       -- scroll only as far as necessary to show a piece

#Buttons

When you click or tap a Button, the engine calls clicked() in its script. Pictures and Panels also get clicked():

-- On a "Play" button
function clicked()
  go("scenes/level1.scene")
end

In a different script, use Play:on("clicked", function() ... end) to listen for the event. In the script of a Button, pressed("jump") is the input function, as in all other scripts.
disabledYou cannot press the Button. Smitten draws it faded
isHovered(), isDown()isHovered(): the pointer is on the Button. isDown(): the pointer holds the Button down
hovered(), unhovered()Events when the pointer comes onto the Button and when it goes off
smitten.mouse.isOverUI()The pointer is on a button or a panel

#Sliders

A Slider sets a number between min and max. Drag its knob, or click a position on its track. step makes the knob move in steps: set it to 1 for whole numbers. When the player moves the Slider, the engine calls changed(value) in its script:

-- On a Slider with min 0 and max 1
function changed(value)
  masterVolume(value)
end

If a script sets value, the knob moves, but the engine does not call changed(). vertical turns the Slider, so that it goes from bottom to top.

#Checkboxes

A Checkbox is a box that you can tick, with words next to it. If you set look to switch, the Checkbox is a switch that slides. When the Checkbox changes, the engine calls toggled(checked):

function toggled(checked)
  fullscreen(checked)
end

For a choice of one item from a set (easy, normal, hard), give the Checkboxes the same group name. In a group, when you tick one Checkbox, the other Checkboxes with that name in the same piece become unticked. Smitten draws Checkboxes in a group as circles:

-- On each of three Checkboxes with group "difficulty"
function toggled(checked)
  if checked then game.difficulty = text end
end

#Typing boxes

A TextInput is a box to type in. To type, click or tap the box. On a phone, the keyboard comes up. A TextInput has:

  • a caret.
  • a selection (drag, or use Shift with the arrow keys).
  • Ctrl+A, copy, cut and paste.
  • Home and End.
  • Ctrl with the arrow keys, to go to the next word.
-- On a TextInput
function submitted(text)       -- the player pressed Enter
  print("Hello, " .. text)
end
PropertyWhat it does
placeholderFaint words when the box is empty: "Your name"
maxLengthThe maximum number of characters in the box
allownumbers, letters, or only (only the characters in allowCharacters)
secretShows dots, not the characters
multilineMore than one line: Enter starts a new line, and Ctrl+Enter submits

The engine calls these functions:

  • changed(text): after each change.
  • submitted(text): when the player presses Enter.
  • focused(): when typing starts.
  • blurred(): when typing stops.

text is the text in the box. You can read it or set it at all times.

While the player types in a TextInput, the keys go to the TextInput and not to the game. For example, "w" does not make the player walk, and the space bar does not make pressed("jump") true. Typing stops when one of these occurs:

  • The player presses Escape.
  • The player presses Tab. The focus goes to the next piece.
  • The player clicks a different position.
  • A script calls blur().

The TextInput uses typed(). To make your own text input without a piece, use typed().

#Skins

Smitten draws Panels, Buttons, TextInputs and Sliders as plain shapes in a color. To draw an image instead, give the piece a skin. When Smitten stretches a skin, the corners keep their shape. skinEdges sets how many pixels at each edge keep their size. Only the middle stretches. For example, take a 24 × 24 image of a wooden frame, and set skinEdges to

  1. This makes a panel of any size with sharp corners.
skinThe image
skinEdges8 for all four edges, or 8, 4, 8, 12: left, top, right, bottom
skinHover, skinDown (Button)Pictures for when the pointer is on the Button, and for when the Button is down. Without them, Smitten draws the skin a little lighter or darker
knobImage (Slider)An image for the knob. skin is the track. color tints the filled part
skin, skinChecked (Checkbox)Pictures for the box when it is not ticked and when it is ticked

If the display setting of the project is pixel, Smitten does not smooth the skins. This is the same for all images.

#Menus for keyboards and gamepads

If you turn on autofocus on a Button, the Button has the focus when the scene starts. This is also possible on a Slider, a Checkbox or a TextInput. Then:

  • The arrow keys, the d-pad and the stick move the focus to the nearest piece in that direction.
  • Tab and Shift+Tab move the focus through the pieces in their order.
  • The piece with the focus shows a ring.
Piece with the focusWhat the keys do
ButtonEnter, Space or gamepad A press it
CheckboxEnter, Space or gamepad A change it to ticked or not ticked
SliderLeft and right move it (up and down for a vertical Slider). Hold the key to continue
TextInputKeys type. Up and down go to the piece in that direction. Tab goes to the next piece. Escape or gamepad B stops the typing

When you click a piece, it also gets the focus. In a script, focus() moves the focus to the piece. When no piece has the focus, the arrow keys go to the game as usual.

All players can use a menu with their keys and gamepads. If a piece has a player (More than one player), only that player can use it. This is also true for the pieces inside it. Because of this, you can make a menu for each player on a split screen.

UI continues to work while the game is paused. Pause menus need this (Pausing).

#A settings screen from these parts

Smitten does not have a ready-made settings menu. This example uses the pieces above. You can make your menu in the shape that your game needs.

Panel      Settings    anchor center, 360 × 250
└ Column   Menu        anchor fill, x 16, y 16, gap 12
  ├ Label    Title       text "Settings"
  ├ Row      VolumeRow
  │ ├ Label    (text "Volume", width 100)
  │ └ Slider   Volume    min 0, max 1, grow 1
  ├ Checkbox Fullscreen  text "Fullscreen", look switch
  ├ Row      NameRow
  │ ├ Label    (text "Name", width 100)
  │ └ TextInput Name     placeholder "Your name", maxLength 12, grow 1
  └ Button   Back        text "Back", autofocus on

The Column stretches each Row to the width of the Column. grow gives the Slider and the TextInput the space that the Labels do not use. You set all of these properties in the Inspector. Three short scripts make the menu work:

-- On the Volume slider
function ready()
  value = load("volume", 1)
  masterVolume(value)
end

function changed(value)
  masterVolume(value)
  save("volume", value)
end
-- On the Fullscreen checkbox
function ready()
  checked = fullscreen()
end

function toggled(checked)
  fullscreen(checked)
end
-- On the Name box
function ready()
  text = load("name", "")
end

function blurred()          -- typing stopped: Enter, Escape, Tab or a click on a different position
  save("name", text)
end

function submitted()
  blur()
end

With a gamepad or the arrow keys, the focus starts on Back. Then it moves up through the Name box, the switch and the slider.

anchorenum"topLeft"The point from which the piece measures x and y. fill covers the screen or the parent UI piece. Inside a Row, Column, Grid or Scroll, that piece decides the position.
xnumber (px)0The distance in from the anchor.
ynumber (px)0The distance in from the anchor.
widthnumber (px)160The width. It has no effect when anchor is fill.
heightnumber (px)40The height. It has no effect when anchor is fill.

#Label

The text of a Label can do all the things on the Text page:

  • tags for colors, sizes and effects in the text (turn on rich).
  • an outline or a shadow.
  • a smaller size, to fit in the Label (fit).
  • one character after the other comes onto the screen (reveal()).
  • links that call linkPressed(name).

Method
measure()Returns the size of the text in its current layout: width, height.
lineCount()Returns the number of lines in the text.
characterCount()Returns the number of characters in the text. Text tags and line breaks do not count.

reveal(charactersPerSecond?, from?)Shows the text one character at a time, like a typewriter (30 characters per second if you do not give a speed). Returns a handle with cancel(), after(fn) and wait(seconds). [pause=0.5] and [speed=10] in rich text change the speed.
skip()Shows all of the text now and stops a reveal().
Event (a function in its script)

function finished()The engine calls it when reveal() has shown all of the text.
function eachCharacter(c)The engine calls it for every character each time it draws the text. Use it to move or color the character: c.y = math.sin(c.time * 4 + c.index) * 3. You can change x, y, rotation, scale, color, alpha and visible of c. You can read index, count, char, line, time and since. The engine uses the same table c for every character, so do not keep it.
function linkPressed(name)The engine calls it when the player clicks or taps a [link=name] in the text.

#TouchStick

A stick for a thumb. It pushes input actions, as the stick of a gamepad does. Input: Touch shows how to put touch buttons and sticks on the screen.

PropertyTypeDefault
leftActionaction"left"The action that it presses when the thumb moves left. With none, it presses nothing in that direction.
rightActionaction"right"The action that it presses when the thumb moves right.
upActionaction"up"The action that it presses when the thumb moves up.
downActionaction"down"The action that it presses when the thumb moves down.
playerint0The player whose actions it presses: 2 for player 2. 0 uses the player of the piece that it is inside, or player 1.
modeenum"fixed"fixed stays in the middle of its rectangle. floating comes to where the thumb touches, anywhere in the rectangle. follow does the same, and moves with the thumb when the thumb goes past the radius.
radiusnumber (px)60How far the thumb moves for a full push. It is also the size of the circle of the stick.
deadzonenumber0.2The part of the radius near the middle that does not count as a push (0.2 is a fifth).
showenum"touch"touch shows it on phones and tablets, and on any screen after a finger touches it. always shows it everywhere, and the mouse can use it. never keeps it invisible, but fingers can still use it.
colorcolor{1, 1, 1, 0.25}The color of the circle of the stick (or a tint for its image).
knobColorcolor{1, 1, 1, 0.6}The color of the knob under the thumb (or a tint for its image).
imageresource""An image for the circle of the stick, instead of the drawn circle.
knobImageresource""An image for the knob, instead of the drawn knob.
Method
getValue()Returns the direction and size of the push: x, y from -1 to 1 (0, 0 when no finger is on the stick).
isActive()Returns true while a finger is on the stick.
Event (a function in its script)

function untouched()The engine calls it when the finger lets go of the stick.

#TouchButton

A button for a finger. While a finger holds the TouchButton down, the input action is down.

PropertyTypeDefault
actionaction"jump"The action that it holds down while a finger is on it. With none, it only tells its script, with touched() and untouched().
playerint0The player whose action it presses: 2 for player 2. 0 uses the player of the piece that it is inside, or player 1.
shapeenum"circle"circle is the largest circle that fits in its rectangle. rectangle is the whole rectangle.
texttext""Words or a letter on the button.
imageresource""An image on the button: an arrow, a sword.
showenum"touch"touch shows it on phones and tablets, and on any screen after a finger touches it. always shows it everywhere, and the mouse can press it. never keeps it invisible, but fingers can still press it.
colorcolor{1, 1, 1, 0.3}The color of the button. The color is stronger while a finger holds the button.

fontresource""A font, or empty for the default font.
sizeint (px)20The font size.
cornerRadiusnumber (px)8Rounds the corners.
