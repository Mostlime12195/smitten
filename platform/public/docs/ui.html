UI

UI pieces draw on top of the game in screen pixels and ignore cameras: Label, Button, Bar, Panel and Picture. A UI piece inside another is laid out inside it.

#Layout

Each UI piece is placed from an anchor (a corner, an edge, center or fill); x and y are the distance in from it. getRect() returns the current screen rectangle. visible and opacity apply to children too.

Message.text = "Level complete"
tween(Message, 0.3, { opacity = 1 })

#Buttons

A Button's script gets pressed() when clicked or tapped (Pictures and Panels too). In a Button's script, read input with smitten.input.pressed, since pressed is the event.

function pressed() go("scenes/level1.scene") end
disabledCan't be pressed; drawn faded
isHovered(), isDown()Pointer over it; held down
hovered(), unhovered()Events
smitten.mouse.isOverUI()Pointer over any button or panel

#Keyboard and gamepad menus

With autofocus on, a Button has focus when the scene starts. The up/down/left/right actions move focus to the nearest button and accept presses it. focus() and isFocused() control it from scripts. Without a focused button, arrow keys go to the game.

UI keeps working while the game is paused; see Pausing.

A UI piece's draw() uses screen pixels from its top-left corner.
