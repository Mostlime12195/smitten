# Smitten docs

Smitten is a 2D game engine that runs in your browser. You make games from
**pieces** in **scenes**. Short Lua **scripts** give the pieces their
behavior. The editor has tools to draw art and make sounds. When the game is
ready, you can publish it, and anyone can play it.

If you are new, start with [Getting started](getting-started.md). It shows
all the steps of a small game, in approximately fifteen minutes. Then try
the [examples](getting-started.md#examples) on the home screen. Each
example is a small project that shows one part of Smitten.

## Where to look

- [Scripts](scripts.md) tells how scripts work: variables, the functions
  that the engine calls, events and waiting.
- [Scenes and pieces](scenes.md) tells how to make scenes from a script,
  how to use tags, how to change scenes and how to pause.
- Some pages each tell about one part of a game. These pages are
  [Input](input.md), [Sound and music](sound.md),
  [Sprite editor](sprite-editor.md), [Camera](camera.md),
  [Backgrounds](backgrounds.md), [Tiles](tiles.md), [Lights](lights.md),
  [Text](text.md), [UI](ui.md), [Animation](animation.md),
  [Physics](physics.md), [Pathfinding](pathfinding.md),
  [Random and noise](random.md), [Saving](saving.md) and
  [Drawing](drawing.md).
- [Sharing and publishing](sharing.md) tells how to put a game on the games
  site. [Clips](clips.md) tells how to save the last seconds of a game as a
  video or a GIF. [Leaderboards](leaderboards.md) tells how to add shared high scores
  to a game on the games site. [Online rooms](online.md) tells how players
  in different places play one game together on the games site.
  [Host interface](host-interface.md) tells how a different site can host
  a game and give it cloud saves.
- [Script API](api.md) and [Pieces](pieces.md) are the full reference.
  They show each function that a script can call, and each property of each
  piece type.
- [Older projects](older-projects.md) tells what changed for projects that
  are older than version 3. It also tells what "Update this project" does.
