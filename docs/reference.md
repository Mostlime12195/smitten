# Smitten docs

Smitten is a 2D game engine that runs in the browser. It's a fork of
[LÖVE](https://love2d.org) 12: all of LÖVE's API works, as `smitten.*` or
`love.*`.

- [Getting started](getting-started.md): a first game.
- [Scripts](scripts.md): how a script works.
- [Script API](api.md): every name a script can use.
- [Pieces](pieces.md): every piece, with its properties, methods and events.
