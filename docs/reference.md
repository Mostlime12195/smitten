# Smitten docs

Smitten is a 2D game engine that runs in your browser. You build games out
of **pieces** arranged in **scenes**, give them behavior with short Lua
**scripts**, draw art and make sounds with the built-in tools, and publish
the result for anyone to play.

If you're new, start with [Getting started](getting-started.md): it walks
through a whole small game in about fifteen minutes.

## Where to look

- [Scripts](scripts.md) explains how scripts work: variables, the functions
  the engine calls, events and waiting.
- [Scenes and pieces](scenes.md) covers building scenes from code, tags,
  changing scenes and pausing.
- [Input](input.md), [Sound and music](sound.md), [Camera](camera.md),
  [Tiles](tiles.md), [Lights](lights.md), [UI](ui.md),
  [Physics](physics.md), [Pathfinding](pathfinding.md),
  [Saving](saving.md) and [Drawing](drawing.md) each cover one part of a
  game.
- [Script API](api.md) and [Pieces](pieces.md) are the full reference:
  every function a script can call, and every piece's settings.
